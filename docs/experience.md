# 『あと何回』体験設計（探索中）

> **状態：探索中。** この文書のどの案も、まだ採用していない。
> 目的は、どの案を選んでも失ってはいけない体験と、各案固有の可能性と危険を保存しておくこと。
> 4章の候補案 A〜E は、作品全体の構造ではなく、concept.md 5章「最後は後から生まれる」を体験させる構造の候補である。

前提となる思想は [concept.md](concept.md) にある。この文書は思想を増やさない。
扱うのは、**その思想を人にどう体験させれば成立するか**、つまりプレイヤーの認識がどの順序で変化する作品なのか、である。

この段階では、次には踏み込まない。

- 実装技術、データ構造
- UI の具体的なレイアウト、細かな操作方法
- 数値パラメータ、確率設計
- ステージ数やイベント数

## 1. 作品全体として失ってはいけない体験

作品の中心テーマは「人は同じ時間を、同じ向きには生きていない」である（concept.md 0章）。
どの形をとるにしても、次の体験を失ってはいけない。

- **何かが積み上がる感覚**（concept.md 2章）
- **何かが減っていく感覚**（concept.md 2章・4章）
- **早く終わってほしい感覚**（concept.md 2章・3章）
- **終わってほしくない感覚**（concept.md 2章・3章）
- **同じ対象に対する感覚が、途中で反転すること**（concept.md 3章・4章）
- **同じ時間でも、人によって意味が違うこと**（concept.md 3章）
- **あとから意味が変わる時間があること**（concept.md 5章）

これらをどれか一つに縮めない。特定の一つの認識の流れを、作品全体の必須ルートにしない。

### 全体を通じた態度

- **面倒は本物である。** 大切な時間を最初から美しいものとして描くだけにしない。繰り返し、急ぎ、飛ばしたくなる気持ちを、プレイヤーが実際に持つ。
- **向きを固定しない。** ある対象を「積み上がる時間」「減っていく時間」と決めつけない。
- **正誤を評価しない。責めない。** 「あのとき正解を選べばよかった」というゲームにしない。面倒だと思ったことも、早く終わってほしいと思ったことも、人間として普通の反応として扱う。
- **視線は最後にプレイヤーの生活へ戻る。** 作品内で感動を完結させない。

## 2. 「後から生まれる最後」を体験させる認識の流れ（一つの可能性）

案 A〜E を比べる中で、案を超えて共通して見えてきた流れ。
**これは作品全体の必須ルートではない。** concept.md 5章の現象を体験させるための、一つの可能性である。
また、ゲーム仕様ではなく、認知の変化の記録である。各段階の長さや、段階同士がどれくらい重なるかは決めていない。

1. **普通の日常として受け取る**
   最初から「これは最後かもしれない」と警戒していてはいけない。現実の最後も、その瞬間にはただの日常だからである。
2. **繰り返しに慣れる**
   日々が手順になっていく。
3. **面倒になったり、雑に扱ったりする**
   早く終わってほしい、飛ばしたい、と感じる。その面倒は本物である必要がある。後になって惜しくなるものが、そのときには面倒だった、という矛盾を残すため。（concept.md 3章）
4. **何かが予告なく来なくなる**
   薄れていく終わり。区切られた終わりではない。（concept.md 4章）
5. **その瞬間には何も知らされない**
   最後だった出来事の瞬間に、演出も通知もない。（concept.md 5-1、5-3）
6. **何も起きない時間が続く**
   最後を作るのは、この「次が起きなかった時間」である。（concept.md 5-1）
7. **プレイヤー自身が「あれ？」と思う**
   気づくのは作品の合図によってではなく、プレイヤー自身である。
8. **過去の普通の日が、後から「最後」だったと分かる**
   その日は特別ではなく、混ざっていて、整っていなかった。（concept.md 5-4）
9. **それ以降、以前とまったく同じようには時間を見られなくなる**
   今日にも、まだ貼られていないラベルがあるかもしれない。（concept.md 5-6）
10. **しかし、すべての瞬間を特別なものとして生きることもできない**
    知ったあとでも、日常はまた日常になる。（concept.md 5-5）
11. **最後はプレイヤー自身の生活へ視線が戻る**
    「自分にも、もう終わっていたことがあるかもしれない」「今日も、何かの途中なのかもしれない」。本当のゴールはゲーム内ではなく、ゲーム終了後にある。（concept.md 7章）

## 3. この流れの中で失ってはいけないこと

2章の流れを扱う場合に、守るべきこと。

- **普通の日常として始まる。** プレイヤーを最初から身構えさせない。
- **最後の瞬間には何も知らせない。** 演出、通知、意味ありげな間を置かない。
- **空白は経験される。** 何も起きない時間を省略して「見せる」のではなく、プレイヤーがその時間を通過する。
- **「あれ？」はプレイヤーの中で起きる。** 作品が答えを差し出さない。
- **最後になった日は整っていない。** 後から綺麗に描き直さない。
- **知ったあとでも、日常はまた日常になる。** それは教訓を忘れたからでも、愛情が足りないからでもない。日常を生きるとはそういうことである。
- **区切られた終わりと混同しない。** 後から最後になったと分かるのは、薄れていく終わりである（concept.md 4章）。

## 4. 候補案（「後から生まれる最後」を体験させる構造）

以下の候補案は、すべて2章の流れを中心に考えたものであり、作品全体の構造の候補ではない。
各案は、2章の流れのどこを強く担うかが違う。どれもまだ候補である。

### 案A：繰り返しの中で、何かが来なくなる

**骨格**：同じような日々を何度も繰り返す。その中のいくつかの要素が、予告なく少しずつ現れなくなる。

- **最初の認識**：これは日常を回す作品だと受け取っている。今日やることを片付ければ一日が終わる。
- **日常の感じ方**：繰り返しは手順になり、慣れて、効率よく、少し雑に処理するようになる。「また今日もこれか」「早く次の日へ」と感じる。
- **違和感が生まれる瞬間**：プレイヤー自身が、ふと**最近あれがない**と気づく。いつからなかったのか、すぐには思い出せない。
- **「最後」が後から成立する感覚**：記憶をたどると、最後にあったのは何でもない日だった。たぶん自分はそれを急いで片付けていた。その日を最後にしたのは、そのあと何も起きなかった時間である。
- **終了後に残るもの**：「自分の生活にも、いつの間にかなくなった繰り返しがあるかもしれない」という感覚。

**固有の可能性**
- 「次が起きなかった時間が最後を作る」という中心命題を、説明なしにそのまま構造にできる。
- 面倒で飛ばした繰り返しが、後から惜しくなる対象そのものになる。

**固有の危険**
- 気づかないまま終わるプレイヤーがいる。
- 一度気づくと警戒しはじめ、日常として受け取れなくなる。この案単独では、気づいたあとの時間の扱いを持っていない。

### 案B：後年から振り返る

**骨格**：ある期間の普通の日々を過ごす。そのあと時間が大きく飛び、後の時点からかつての日々を見返す。

- **最初の認識**：普通の日々を過ごしている。
- **日常の感じ方**：面倒も繰り返しもある。ただし「あとで振り返るパートが来る」と構造が予感させるぶん、少し身構えるかもしれない。
- **違和感が生まれる瞬間**：時間が飛んだあと、今の日常にかつての何かがないことに気づく。
- **「最後」が後から成立する感覚**：過去と現在を見比べて、空白の期間が見える形で、あの日が最後だったと分かる。
- **終了後に残るもの**：懐かしさ、少しの喪失感。

**固有の可能性**
- すべてのプレイヤーに、確実に「後から知る」体験を届けられる。

**固有の危険**
- 時間が飛ぶ瞬間そのものが、作品からの合図になる。区切られた終わりに近づく。
- 何も起きない時間を「経験」させずに省略して「見せる」ことになり、3章の「空白は経験される」を失いやすい。
- 思い出の総集編のように、綺麗になりすぎる。

### 案C：同じ場面が、間隔を置いてめぐってくる

**骨格**：毎年の行事、季節、決まった場所など、同じ型の場面が長い間隔を置いて何度も訪れる。

- **最初の認識**：毎回の場面を、それ自体として受け取っている。また今年も来た、という感覚。
- **日常の感じ方**：行事には準備や移動の面倒がある。そして「また次もある」と思っている。
- **違和感が生まれる瞬間**：いつもの場面が来たのに、何かが欠けていることに気づく。同じ型が繰り返されるので、欠落が見えやすい。
- **「最後」が後から成立する感覚**：前回が、全部が揃った最後の回だったと分かる。前回の自分はそれを「毎回のひとつ」として過ごしていた。
- **終了後に残るもの**：「家族全員で最後に集まった年は、いつだったか」という、自分の生活の中の周期への視線。

**固有の可能性**
- 「全員が揃った最後の日」「最後の家族旅行」のような、薄れていく終わりと相性が良い。
- 長い時間の単位を扱える。

**固有の危険**
- パターンが読まれやすい。二回目以降、場面が来るたびに「今回は何が欠けるか」と探すようになり、日常として受け取れなくなる。

### 案D：作品の外側の時間も、空白に含まれる

**骨格**：最後を作る「何も起きない時間」は、作品の中だけにあるとは限らない。プレイヤーが作品を閉じている時間、つまりプレイヤー自身の生活の時間も、その空白に含まれうる、という考え方。
現実の何週間にもわたって断続的に遊ぶ形式は、その一つの形にすぎず、必須ではない。

- **最初の認識**：作品に触れている時間と、そうでない時間を区別している。
- **日常の感じ方**：開くこと自体が面倒な日も、開かない日もある。作品との付き合い方そのものが、繰り返しの一つになる。
- **違和感が生まれる瞬間**：作品の外、自分の生活の中のどこかで、「そういえば」と思う。
- **「最後」が後から成立する感覚**：最後を作る空白が、作品の中で省略されるのではなく、プレイヤーの現実の時間として実際に流れる。
- **終了後に残るもの**：作品と生活の境目が曖昧になる。

**保存しておく発見**
> プレイヤーがこの作品を最後に開いた日も、その瞬間には最後だと知らない。

作品を途中でやめること、いつの間にか起動しなくなることすら、この作品のテーマの外側ではない。作品そのものが、薄れていく終わりの一例になりうる。

**固有の可能性**
- 「本当のゴールはゲーム終了後にある」に、最も直接つながる。
- 最後を作る空白が、本物の時間になる。

**固有の危険**
- 体験の質がプレイヤーの生活に大きく左右され、設計で保証しにくい。
- 長期形式をとる場合、途中で離れる人が多い（それ自体は主題に沿っているが、何も届かないまま離れることもある）。

### 案E：知ったあとでも、日常はまた日常になる

**骨格**：一度、後から最後に気づく体験をする。そのあとも日常は続く。気づいたことで少し敏感になるが、やがてまた普通の日常に戻っていく。

これは「知っていたのに守れなかった」構造ではない。「今度こそ全部を大切にしようとして、また見逃す」という形にすると、「ちゃんと大切にできたか」「また見逃したか」を問う試験や反省のゲームに見える。この案はそれを避ける。

- **最初の認識**：普通の日常（案Aと同じ）。
- **日常の感じ方**：気づいた直後は少し敏感になり、いくつかのことを少し丁寧に扱う。しかし数日たてば、また面倒だと思い、急ぎ、何も意識せず一日を終える。それは教訓を忘れたからでも、愛情が足りないからでもない。日常を生きるとはそういうことである。
- **違和感が生まれる瞬間**：劇的な瞬間ではない。気づいたはずの感覚が、いつの間にかまた日常の中に溶けている、と静かに感じる程度のもの。
- **「最後」が後から成立する感覚**：知ったあとでも、最後はやはり後からしか分からない。最後があると知っていても、中にいるあいだはラベルを貼れない。（concept.md 5-3）
- **終了後に残るもの**：日常に戻ることは忘却でも失敗でもない、という理解。そして「今日も、何かの途中なのかもしれない」という、責めのない感覚。

**固有の可能性**
- 「すべての瞬間を儀式のように大切にし続けることはできない」（concept.md 5-5）を、体験として扱える。
- 気づいたあとの時間を、避けるべき問題ではなく作品の一部として扱える。

**固有の危険**
- 作品が「どれだけ丁寧に扱ったか」を少しでも測ったり映したりすると、すぐに試験や反省のゲームに戻ってしまう。
- 気づきが日常に溶けていく過程が、平板で印象に残らないものになりうる。
- 「人はどうせ忘れる」という冷笑に読まれる危険がある。

## 7. 不足している体験の候補（F〜N）と俯瞰

6章で、候補案 A〜E がほぼすべて「あとから意味が変わる時間」に寄っていることが分かった。
この章の目的は、作品案を大量に用意することではない。これまで不足していた次の三つの体験にも候補が存在することを確認するためのものである。

- 積み上がる時間
- その場で反転する時間
- 見る人によって向きが違う時間

どの候補も採用していない。統合もしていない。
**候補案の追加はこの章で終了する。O 以降の案は作らない。**

### テーマ1：積み上がる時間

#### 案F：昨日の自分が、今日の足場になる

**骨格**：最初はぎこちなく、手間のかかることを繰り返す。続けるうちに、それが手に馴染んでいく。

- **最初の認識**：面倒で、うまくいかない作業だと感じている。
- **向きが変わる瞬間**：以前は苦労していたことを、意識せずにこなしている自分に気づく。そしてその先に、以前は見えなかった「次にやれること」が見える。
- **気づくこと**：一日が終わることが、明日の自分を少し有能にしていた。終わることで、未来の選択肢が増えている。
- **concept.md で担う部分**：2章（仕事は自分の側に蓄積し、明日へ持ち運べる。未来が広がる）
- **危険**
  - ゲームにありがちな「成長して強くなる」仕組みに吸い込まれ、作品の主題ではなく報酬の繰り返しになる。
  - 「仕事は前向き、家族は寂しい」という単純な対比に読まれる。

#### 案G：完成が、次の入口になる

**骨格**：何かを作り上げる、長い取り組み。案Fが自分の内側に残る力なのに対し、こちらは世界の側に残るものである。

- **最初の認識**：まだ形のないものに向かって、少しずつ手を動かしている。
- **向きが変わる瞬間**：ひとつが完成した瞬間。終わったことが嬉しく、同時に、その完成によって次にやれることが見えてくる。
- **気づくこと**：終わることが、喪失ではなく入口になる時間がある。
- **concept.md で担う部分**：2章（行為の外側に完了条件がある。終わらせることに意味がある）
- **危険**
  - 達成感そのものが目的になり、「達成ゲーム」になる。
  - 作ったものが評価や点数と結びつくと、正誤を評価しないという原則と衝突する。

#### 案H：明日が待ち遠しい

**骨格**：今日の積み上げによって、明日やりたいことがはっきりしている状態。

- **最初の認識**：今日を進めている。
- **向きが変わる瞬間**：一日の終わりに、早く明日になってほしいと感じる。ただしそれは面倒だからではなく、明日が楽しみだからである。
- **気づくこと**：「早く次へ進みたい」には、消化の「早く終わってほしい」とは逆の向きがある。どちらも時間を先へ送りたい気持ちだが、その理由がまったく違う。
- **concept.md で担う部分**：0章（時間の向きが複数ある）、2章（未来が広がる）
- **危険**
  - 消化の「早く終わってほしい」と区別がつかず、どちらもただの「先送り」に見えてしまう。

### テーマ2：その場で反転する時間

#### 案I：境界をまたぐ

**骨格**：短く連続した時間の中に、一つの境界がある。寝かしつけて子どもが寝る瞬間や、旅行に出発する瞬間などである。

- **最初の認識**：境界の手前では、早く終わらせたい、行くのが面倒だと感じている。
- **向きが変わる瞬間**：境界を越えた直後。対象は何も変わっていないのに、自分の時間の向きだけが変わる。
- **気づくこと**：「さっきまで早く終わってほしかったのに」。終わらせたかったものと、惜しいものが、同じ対象だった。
- **concept.md で担う部分**：3章（同じ人の中でも反転する）、4章（境界を越えた瞬間に意味が反転する）
- **危険**
  - 音楽や光などの演出で反転を合図すると、作品が感情を指示することになる。
  - 合図をまったく出さないと、反転が起きないまま通り過ぎるかもしれない。

#### 案J：残りが見えた瞬間

**骨格**：終わりのある時間（旅行など）。始まったばかりのころは、残りが豊富にあって意識されない。

- **最初の認識**：まだたっぷりあると感じていて、数えていない。
- **向きが変わる瞬間**：ある時点で、残りが見えるようになる。半分を過ぎた、あと一日しかない、など。同じ過ごし方をしていても、そこから時間が「減っていくもの」に変わる。
- **気づくこと**：時間そのものは何も変わっていないのに、残りが見えたことで惜しさが生まれた。
- **concept.md で担う部分**：4章（残りが見えないものは無限に見える。惜しさは、残りが見えたときに生まれる）、6章（区切られた終わりにとっての「あと何回」）
- **危険**
  - 残りを数字で示すと、「数字で迫らない」という原則に触れる。
  - 示し方次第で、ただのカウントダウン演出になる。

#### 案K：手が空いた瞬間に、もう一つの層が現れる

**骨格**：自分が動かす時間と、ただそこにある時間が、同じ場面に重なっている。プレイヤーは動かす側の作業に追われている。

- **最初の認識**：やることを片付けている。それ以外は目に入っていない。
- **向きが変わる瞬間**：最後の作業が終わって手が空いた瞬間。ずっとそこにあった時間が、急に見えるようになる。
- **気づくこと**：「ただそこにある時間」は、なかったのではない。受け取る余白がなかっただけだった。
- **concept.md で担う部分**：3章（二つの層が同じ一日に重なる、受け取る余白）
- **危険**
  - 「作業は悪く、自由な時間は良い」という教訓に読まれる。
  - 手が空いたあとの時間が、退屈なだけになる。

### テーマ3：見る人によって向きが違う時間

#### 案L：同じ一日を、別の人として通る

**骨格**：同じ一日を、違う人の立場で二度通る。親Aと親B、あるいは親と子。

- **最初の認識**：一つ目の立場で、その一日の向きを自然に生きる。
- **向きが変わる瞬間**：二つ目の立場で同じ出来事に出会ったとき、その出来事が逆の向きの時間になっている。
- **気づくこと**：同じ一日が、片方には「＋1」、もう片方には「−1」だった。どちらも本当だった。
- **concept.md で担う部分**：3章（見る側によって向きが逆になる、宝物にも重荷にもなる）
- **危険**
  - 二つを並べると、どちらが正しいか、どちらが良い親か、という比較を招く。
  - 二回目は答えを知った状態で通るので、気持ちではなく理解になってしまう。
  - 「相手の立場に立ちましょう」という説教になりやすい。

#### 案M：隣にいる人の向きは見えない

**骨格**：プレイヤーは一人の立場だけを生きる。同じ時間を、隣の人物が違う向きで生きている。

- **最初の認識**：自分の向きが、その時間のすべてだと思っている。
- **向きが変わる瞬間**：説明ではなく、相手のちょっとした様子から、相手がまったく逆の向きで同じ時間を生きていたと気づく。自分は終わってほしいのに、子どもは明日を楽しみにしていた、など。
- **気づくこと**：同じ場にいて、同じ時間を過ごしていても、向きは共有されていない。
- **concept.md で担う部分**：3章（見る側によって向きが逆になる）
- **危険**
  - 説明しないぶん、気づかれないまま終わることがある。
  - 隣の人物が、プレイヤーに気づかせるためだけの道具になる。

#### 案N：プレイヤー同士で向きが違う

**骨格**：同じ場面を、どちらの向きでも受け取れるように作る。どう受け取るかは、プレイヤーそれぞれの生活や状態によって変わる。

- **最初の認識**：自分が感じた向きが、その場面の意味だと思っている。
- **向きが変わる瞬間**：作品の外で、他の人が同じ場面をまったく逆の向きで受け取っていたと知るとき。
- **気づくこと**：「あの場面を惜しいと思ったのは自分だけだった」「あの人には、あれが重荷だった」。
- **concept.md で担う部分**：3章（人によって違う、受け取る余白）、7章（視線が生活に戻る）。案Dと同じく、作品の外側を使う。
- **危険**
  - 作品の外での会話や共有に頼るので、起きるかどうかを保証できない。
  - 「あなたは〇〇タイプ」のような診断にすると向きが固定され、「向きを固定しない」という原則に反する。

### 俯瞰：作品全体で体験できる時間の種類

A〜N を、三つの観点で並べる。何の向きを担うか、どれくらいの時間差で起きるか、誰の視点か。

| 案 | 主に担う向き | 時間差 | 視点 |
|---|---|---|---|
| A 繰り返しと欠落 | 減る（薄れる）／後から惜しい | 長い | 自分 |
| B 後年から振り返る | 減る（薄れる）／後から惜しい | 長い（省略して見せる） | 自分 |
| C 同じ場面がめぐる | 減る（薄れる）／後から惜しい | 長い（周期） | 自分 |
| D 作品の外側の時間 | 後から意味が変わる | 作品の外 | 自分（現実） |
| E 日常はまた日常に | 知ったあとの消化と惜しさ | 長い | 自分 |
| F 昨日が足場になる | 積み上がる（内側に） | 日々 | 自分 |
| G 完成が入口になる | 積み上がる（世界の側に）／終わることが嬉しい | 区切り | 自分 |
| H 明日が待ち遠しい | 早く次へ（期待） | 日々 | 自分 |
| I 境界をまたぐ | 終わらせたい → 終わってほしくない | その場 | 自分 |
| J 残りが見えた瞬間 | 数えていない → 減る（残りが見える） | 短い | 自分 |
| K 手が空いた瞬間 | 動かす層 → ただそこにある層 | その場 | 自分 |
| L 別の人として通る | ＋1 ⇔ −1 | 同じ一日 | 他者（交代） |
| M 隣の人の向き | 自分の向き ⇔ 他者の向き | 同じ時間 | 他者（隣） |
| N プレイヤー同士 | 受け取り方の違い | 作品の外 | プレイヤー間 |

#### 1章の7つの体験との対応

| 体験 | 主に担う候補 |
|---|---|
| 何かが積み上がる感覚 | F、G、H |
| 何かが減っていく感覚 | A、B、C（薄れる形）、J（残りが見える形） |
| 早く終わってほしい感覚 | A、E、I、K（Hは逆の理由で先へ進みたい） |
| 終わってほしくない感覚 | I、J（その場で）、A〜E（後から） |
| 同じ対象への感覚が途中で反転する | I、J、K（その場で）、A〜E（時間差で） |
| 同じ時間でも人によって意味が違う | L、M、N |
| あとから意味が変わる時間がある | A〜E |

#### 俯瞰して見えること

- **7つの体験すべてに、少なくとも一つの候補が届くようになった。** 6章で「―」だった積み上がる感覚と人による違いにも、候補ができた。
- **時間の幅が揃った。** その場（I、K）、日々（F、H）、短い区切り（G、J）、長い時間（A〜C、E）、作品の外（D、N）。
- **視点の幅も揃った。** 自分、隣の他者、交代する他者、プレイヤー同士。
- **まだどの候補も担っていない向きがある。** 積み上がる時間そのものが反転すること（たとえば、楽しかった仕事が重荷に変わる）を担う候補は、まだない。concept.md 8章の「向きを固定しない」は仕事にも当てはまるはずだが、今の候補は「仕事＝積み上がる」に固定されている。
- **テーマごとに共通する危険が違う。**
  - テーマ1：成長や達成というゲームの定番に吸い込まれること
  - テーマ2：演出で感情を指示してしまうこと
  - テーマ3：並べた途端に比較と評価が始まること

### 候補の系統（時間体験の地図）

採用判断ではなく、ゲーム構造の決定でもない。この作品が扱おうとしている時間体験の地図として、現時点の案を四つの系統に整理する。
同じ系統の中に似ている案があっても、統合や削除はしない。

1. **積み上がる時間**：F／G／H
2. **その場で向きが反転する時間**：I／J／K
3. **人によって向きが異なる時間**：L／M／N
4. **あとから意味が変わる時間**：A／B／C／D／E

次の段階では、どの案を採用するかではなく、**各系統で本当に失ってはいけない体験の核**を見つける。

## 8. どの案を選んでも残る問い

- **作品全体の体験構造は、まだ検討していない。**
  1章の体験をどう含むかは未定であり、4章の候補案はその一部（5章の現象）を担うものにすぎない。

- **気づかないまま終わるプレイヤーをどう扱うか。**
  現実でも、最後に気づかないまま過ぎていくことは多い。それを許すのは誠実だが、作品としては何かが届かなくなる。
- **面倒を本物にすると、離脱が増える。**
  面倒が演出だと伝わると、後で惜しくなる感覚も弱まる。一方で、本当に面倒なら、やめてしまう人もいる。（案Dの観点では、やめること自体もテーマの外側ではない。）
- **二回目のプレイ。**
  一度知ったプレイヤーは、最初から警戒した状態で始める。これを壊れと見なすか、「今日は、まだ何の日でもない」（concept.md 5-6）の体験として受け入れるか。
