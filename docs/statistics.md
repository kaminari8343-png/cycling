# 使う統計と出典

方針は [design.md](design.md) の「家族の状況：国と統計」。作り手が数字をつくらない。

データは `data/countries.json`（167か国、人口50万人以上）。項目ごとに、各国で値のある最新の年を使い、その年も `years` に残している。

---

## 出典

- **世界銀行 世界開発指標（WDI）**：datahub.io が GitHub で公開している写し（`datasets/world-development-indicators`）から取得。多くの項目は2023〜2025年の値。
- **Our World in Data**（`owid/covid-19-data` の最新ファイル）：人間開発指数（国連開発計画）、一人あたりGDP、年齢の中央値。世界開発指標に値がない国の、人口・平均寿命・貧困率の補いにも使う。

## 代わりの推定（統計が入ったら置き換える）

- **極度の貧困の割合が欠けている国**：人間開発指数との関係から推定し、出力に「（推定）」と出す。
- **所得の層**：最も貧しい層に生まれる確率は極度の貧困の割合。残りの4層の配分は、人間開発指数とジニ係数で変える。
- **統計のない出来事の起きやすさ**：「汚職」「差別」「洪水」などに連動する出来事は、人間開発指数が低いほど起きやすくしている。
- **親のもともとの価値観**：人間開発指数が低いほど安全・伝統・同調を、高いほど自律・普遍主義を少し強くし、そこに個人差を足している。世界価値観調査で見られる傾向の向きに合わせただけで、国ごとの実際の分布ではない。
- **子どもの障害**：一律5%。
