# 使う統計と出典

方針は [design.md](design.md) の「家族の状況：国と統計」。作り手が数字をつくらない。

---

## いま入っているもの

`data/countries.json`（167か国、人口50万人以上）。出典は Our World in Data が GitHub で公開しているファイル（`owid/covid-19-data` の `public/data/latest/owid-covid-latest.csv`）。

| 項目 | 元の出典 | シミュレーターでの使い道 |
|---|---|---|
| 人口 | 国連 世界人口推計 | 生まれる国の選び方（出生数の代わり） |
| 平均寿命 | 国連 世界人口推計 | 親と子の死亡の確率 |
| 極度の貧困の割合 | 世界銀行 | 最も貧しい層に生まれる確率 |
| 一人あたりGDP | 世界銀行 | （まだ使っていない） |
| 年齢の中央値 | 国連 世界人口推計 | （まだ使っていない） |
| 人間開発指数 | 国連開発計画 | 所得の層の分け方、制度や医療が届くか、厳しい出来事の起きやすさ、親のもともとの価値観（仮） |

このファイルは数年前の値を含む。世界銀行のAPIに届かない間のつなぎとして使っている（下の「取れない理由」）。

## いまの代わりの推定（統計が入ったら置き換える）

- **極度の貧困の割合が欠けている49か国**：人間開発指数との関係から推定し、出力に「（推定）」と出す。
- **所得の層**：最も貧しい層に生まれる確率は極度の貧困の割合。残りの4層は人間開発指数で配分を変えている。
- **乳幼児の死亡**：平均寿命から、0歳の死亡の確率を足している。
- **厳しい出来事の起きやすさ**：「紛争」「汚職」「差別」などに連動する出来事は、人間開発指数が低いほど起きやすくしている。
- **親のもともとの価値観**：人間開発指数が低いほど安全・伝統・同調を、高いほど自律・普遍主義を少し強くし、そこに個人差を足している。世界価値観調査で見られる傾向の向きに合わせただけで、国ごとの実際の分布ではない。
- **子どもの障害**：一律5%。

## 取れない理由

作業環境のネットワーク設定で、`api.worldbank.org` への接続が許可されていない。環境の設定で、このホスト（とユニセフや世界保健機関のデータのホスト）を許可すれば、取得スクリプトを書いて上の表を埋められる。世界価値観調査のデータは、公式サイトで利用登録をしてから手で取得する必要がある。
