# 『あと何回』設計（現行）

この文書が現在の基準。`concept.md` と `experience.md` は、ここに至るまでの検討の経緯として残している。

---

## 一言で

価値観の診断に答えると、その思想を持った親が、ランダムな家族の中で勝手に生きていく。
最後に、**あなたの思想が入らなかった「本来の人生」**と、**入ったことで変わった人生**の年表が並ぶ。

---

## 構成

### 第1部：価値観の診断

- 100問前後の、よくある診断テストの形式。
- 結果として「あなたは〇〇タイプ」が出る。ここで一度、診断ゲームとして完結させる。
- 生活の場面（子ども、仕事、学校など）は出さない。子どもがいない人、仕事をしていない人、学校に通っていない人にも答えられるように、**何を大事にして生きているか**という上の段の価値観だけを測る。
- 人は矛盾した価値観を同時に持っている。それをそのまま拾う。

#### 診断を単体で面白くする

最初の診断で満足させることが必須。ここが面白くなければ第2部まで進まない。ここが面白ければ、結果を人に見せたくなる。そのため質問は多く、複雑でもよい。代わりに結果をとがらせる。

**土台：シュワルツの基本的価値観理論**

10の価値（自律、刺激、快楽、達成、権力、安全、同調、伝統、慈善、普遍主義）を測る。研究用の質問紙（PVQ）の文面は使わず、この作品用に書いた質問を使う（[questions.md](questions.md)）。

- 10の価値は円の形に並び、向かい合う価値は両立しにくい。両方を強く大事にしていれば、それが構造的な矛盾になる。
- 大きな二軸：**変化への開放 ⇔ 保守**、**自分を高める ⇔ 自分を超える**。
- 世界価値観調査には、国ごとの価値観の実データがある。「本来の人生」の親の価値観を、その国の人々の分布から選べる可能性がある（使える項目は要確認）。

**答え方**
- 人物描写60問：「こういう人は、あなたにどれくらい似ていますか？」に4段階で答える。
- 二択12問：「どちらかしか選べないなら」。言葉では両方を大事にしていても、選ぶときにどちらを取るかのずれを拾う。
- 順位1問：自由／安心／成功／愛／正しさ。

**矛盾の取り方**
- 向かい合う価値を、両方とも強く大事にしている（例：権力⇔普遍主義「平等を語りながら、上に立ちたい。」）
- 人物描写と二択のずれ（例：自由にも安心にも「似ている」と答えたのに、二択ではいつも安心を選ぶ）

**タイプ：10タイプ＋矛盾の副題**

最も強い価値でタイプを決め、最も強い矛盾を副題にする。（以前の16タイプは旧10軸の組み合わせだったため廃止）

| 最も強い価値 | タイプ名 |
|---|---|
| 自律 | 孤高の異端者 |
| 刺激 | 火に飛び込む冒険者 |
| 快楽 | 刹那の享楽家 |
| 達成 | 野心に燃える成功者 |
| 権力 | 独裁的支配者 |
| 安全 | 城壁を築く守り人 |
| 同調 | 空気を読む従者 |
| 伝統 | 掟の継承者 |
| 慈善 | 身内に尽くす献身家 |
| 普遍主義 | 理想に殉じる革命家 |

例：**独裁的支配者 ── 平等を語りながら**

**シミュレーションとの役割分担**
- 診断は、上の段の価値観だけを測る。
- 出稼ぎ、学費、介護のような個別の場面でどう判断するかは、シミュレーションの側で、この10の価値から決める。

**結果ページ**
1. タイプ名と一言（例：「あなたは独裁的支配者タイプです。正しさを知っているのは自分だけだと、どこかで思っている。」）
2. 10の価値の円グラフ
3. **あなたの矛盾**（結果の目玉）：本人の答えをそのまま引いて突きつける。
   例：自由にも安心にも「とても似ている」と答えた。でも、どちらかを選ぶときは、いつも安心を選んだ。**冒険に憧れながら、扉には鍵をかける。**
4. 第2部への一文：「この思想を、地球のどこかの、誰かの親に入れてみますか？」

### 第2部：他人の人生のシミュレーション

- ランダムな家族が生まれる。貧困地域の家族、裕福な家族、障害を抱えた家族など。状況は作り手が考えず、国と統計に任せる（下の「家族の状況：国と統計」）。
- **プレイヤーの思想は、その家族の親に入る。**
- 親は、その思想で勝手に生きていく。プレイヤーは介入しない。
- 見せる期間は、**子どもの代まで**。
- 見どころは、**状況と思想がぶつかったとき**に、家族の人生がどう変わるか。

### 終わり：本来の人生との比較

- 同じ家族、同じ生まれ、同じ偶然の出来事で、親の中身だけが違う二つの人生を並べる。
  - **本来の人生**：親は**その人自身のもともとの価値観**（生まれ育った環境に合った性格）で生きる。
  - **あなたの思想が入った人生**：親の中身がプレイヤーの思想に置き換わる。
- 年齢ごとの年表（沿革）を左右に並べ、どこから分かれたかを見せる。子どもの年表も両方並べる。
- 良い悪いの判定はしない。何歳で何が起きたかの差だけを見せる。
- プレイヤーは、それを自分の幸せの物差しと照らし合わせる。
  「この状況に自分の思想を入れると、もっと悲惨になるのか」
  「でも、ここは救われている」
  という、割り切れない気持ちが残る。

## 家族の状況：国と統計

- 生まれる国は、**世界の出生数に比例して**選ぶ。
- 家族の状況は、その国の統計から確率で決める。
  - 所得（その国の所得分布のどの層に生まれるか）
  - 平均寿命、乳幼児死亡率
  - 教育（就学率、進学率）
  - 障害の有病率
  - 失業率
  - 婚姻・離婚、出生数（きょうだいの数）
- 人生の偶然の出来事（病気、失業、死別）も、その国の確率で起こす。
- 数字は世界銀行、国連、WHOなどの公開統計を使い、出典をゲーム内に明記する。作り手が数字をつくらない。
- 国の平均だけでは粗いので、少なくとも所得の層は国内の分布から選ぶ。
- 統計がない国や項目は、地域の平均で埋めるなどの扱いを決める。

## 判断の仕組み

**出来事 → 選択肢 → 判断 → 結果**

1. **出来事**：年ごとに、その国の統計の確率で起きる。二つの人生（本来／あなた）では同じ乱数を使い、同じ年に同じ出来事が起きるようにする。出来事の一覧は [events.md](events.md)。
2. **選択肢**：選択肢ごとに、どの価値に訴えるか（＋／−）が付いている。状況（所得、借金、頼れる親族の有無など）によっては、選べない選択肢がある。思想と状況がぶつかるのは、ここ。
3. **判断**：親の10の価値と、選択肢の訴えの掛け算で重みを出し、確率的に選ぶ。重みの差が小さければ、どちらに転ぶか分からない。
4. **矛盾は、追い詰められたときに出る**：向かい合う価値を両方強く持つ人は、その二つがぶつかる選択で五分五分に近くなる。どちらに転ぶかは、追い詰められ具合で傾く。
   - 余裕があるとき：伸びていく側の価値（自律、刺激、慈善、普遍主義）が出やすい。
   - 追い詰められたとき：身を守る側の価値（安全、同調、伝統、権力）が出やすい。
   - シュワルツの理論で、価値を「成長・不安のない側」と「自己防衛・不安を避ける側」に分ける考え方に沿う。
   - 追い詰められ具合は、借金、病気、失業、死別などで溜まり、時間とともに戻る。
5. **結果は事実として残す**：幸福度ではなく、所得の層、住む場所、誰と暮らしているか、健康、子どもの教育の段階、家族と会う頻度などの事実として記録する。同じ選択でも、結果は確率で変わる。
6. **子どもの価値観**：親から受け継ぐ、親への反発（親が権力や同調を強く押しつけるほど起きやすい）、育った状況（貧しさや不安定さは安全を強め、外の世界に触れることは開放を強める）の三つが混ざってできる。大人になった子どもは、自分の価値観で、同じ仕組みを使って自分の人生を判断する。
7. **分かれ目にはプレイヤーの答えを添える**：判断に一番効いた価値を記録し、その価値でプレイヤーが一番強く「似ている」と答えた質問を引用する。
   例：「14歳　ハルは学校をやめ、市場で働きはじめた。── あなたの『安心して暮らせることを、何より大事にする人』に『とても似ている』という答えが、この親にそうさせた。」

出来事の数は、面白さに直結する。少ない数で試しても判断できないので、かなり増やしてから回す。

## シミュレーター（試作）

`sim/` に、判断の仕組みを動かす試作がある。

- `node sim/parse-events.mjs`：[events/](events/) の200件を読み取り、`sim/events.json` にする。
- `node sim/run.mjs [seed] [dictator|keeper|heretic]`：一つの家族を、本来の人生とあなたの思想が入った人生で比べて出力する。
- `node sim/samples.mjs`：出力例を [samples.md](samples.md) に書く。
- `node sim/build-play.mjs`：エンジン、結果の文章、出来事、統計を `play/` に写す。`play/index.html` が、診断からシミュレーションまでを通して遊べる試作。
- 統計は `data/countries.json`。出典と、まだ入っていない統計は [statistics.md](statistics.md)。

確率や価値の重み、結果の読み取り方はすべて仮。年表がどう出るかを見るためのもの。

## 仕組みの考え方（実装ではない）

- **価値観**：診断で測った10の価値を持つ。向かい合う価値を両方強く持つ場合は「どちらにも引っ張られる不安定な状態」として持ち、どちらに転ぶかは、そのときのストレスや状況で変わる。
- **出来事**：生まれた状況（お金、地域、健康、家族構成）から起きる。
- **行動**：出来事ごとに、親は自分の思想に従って行動する。その行動が家族のほかの人に影響する。子どもは、親の思想を受け継ぐことも、反発することもある。
- **偶然をそろえる**：失業、病気、出会いなどの偶然の出来事は、二つの人生で同じ年に同じように起こす。違いは、親の判断とその結果からだけ生まれるようにする。
- **分かれ目を見せる**：年表の分岐点に、原因になった回答を添える。
  例：「ここで、あなたの『家族が困っていたら何よりも優先する』という答えが、この人に仕事を辞めさせた」

10の価値とタイプは、第1部の「診断を単体で面白くする」を参照。

---|---|
| 立ち向かう ⇔ 逃げる | 「苦しいことには、何があっても立ち向かうべき」／「苦しいときは逃げ出してもいい」 |
| 仕事 ⇔ 家族 | 「仕事で結果を出すことが家族を守ること」／「家族が困っていたら何よりも優先する」 |
| 自分でなんとかする ⇔ 頼る | 「人に迷惑をかけてはいけない」／「困ったときは助けを求めるべき」 |
| 平等 ⇔ 実力 | 「世の中は平等であるべきだ」／「努力した人が多く得るのは当然だ」 |
| 安定 ⇔ 挑戦 | 「家族がいるなら冒険はしない」／「後悔しない生き方をしたい」 |
| 我慢する ⇔ 表に出す | 「弱いところは子どもに見せない」／「つらいときはつらいと言っていい」 |
| 道を示す ⇔ 任せる | 「子どもには正しい道を教えるべき」／「子どもの人生は子どもが決める」 |
| 世間 ⇔ 自分の基準 | 「周りにどう見られるかは大事だ」／「人と違っていい」 |

## 守ること

- **プレイヤーの価値観を採点しない。** 結果がどれだけ厳しくても、「あなたの考えが間違っていた」とは言わない。
- **どちらの人生が良かったかを、作品の側で決めない。** 片方がいつも良く見える作りにしない。物差しによって評価が入れ替わるようにする。
- **貧困や障害を、思想の良し悪しへの罰や試練に見せない。** 状況はただ与えられるものとして、敬意を持って描く。
- **幸福をパラメーターで測らない。** 親子の関係も人生の良し悪しも、いつ、誰の目線で、何をもって測るかで変わる。だから数値で判定しない。

## 底に置くもの

「あと何回」「最後の日」は作者の思想であり、メインテーマにはしない。
年表の中に、強調も説明もせずに置いておく。感じる人だけが感じればいい。

例：「父と最後に二人で食事をしたのは、41歳の冬だった」
