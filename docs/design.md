# 『あと何回』設計（現行）

この文書が現在の基準。`concept.md` と `experience.md` は、ここに至るまでの検討の経緯として残している。

---

## 一言で

価値観の診断に答えると、その思想を持った親が、ランダムな家族の中で勝手に生きていく。
最後に、**あなたの思想が入らなかった「本来の人生」**と、**入ったことで変わった人生**の年表が並ぶ。

---

## 構成

### 第1部：価値観の診断

- 100問前後の、よくある診断テストの形式。
- 結果として「あなたは〇〇タイプ」が出る。ここで一度、診断ゲームとして完結させる。
- 質問には、わざと矛盾が出る組を混ぜる。人は矛盾した価値観を同時に持っている。それをそのまま拾う。
  - 「苦しいことには、何があっても立ち向かうべき」／「苦しいときは逃げ出してもいい」
  - 「仕事と家族、どちらが大切か」／「家族が困っていたら何よりも優先する」
  - 「世の中は平等であるべきだ」

### 第2部：他人の人生のシミュレーション

- ランダムな家族が生まれる。貧困地域の家族、裕福な家族、障害を抱えた家族など。状況は作り手が考えず、国と統計に任せる（下の「家族の状況：国と統計」）。
- **プレイヤーの思想は、その家族の親に入る。**
- 親は、その思想で勝手に生きていく。プレイヤーは介入しない。
- 見せる期間は、**子どもの代まで**。
- 見どころは、**状況と思想がぶつかったとき**に、家族の人生がどう変わるか。

### 終わり：本来の人生との比較

- 同じ家族、同じ生まれ、同じ偶然の出来事で、親の中身だけが違う二つの人生を並べる。
  - **本来の人生**：親は**その人自身のもともとの価値観**（生まれ育った環境に合った性格）で生きる。
  - **あなたの思想が入った人生**：親の中身がプレイヤーの思想に置き換わる。
- 年齢ごとの年表（沿革）を左右に並べ、どこから分かれたかを見せる。子どもの年表も両方並べる。
- 良い悪いの判定はしない。何歳で何が起きたかの差だけを見せる。
- プレイヤーは、それを自分の幸せの物差しと照らし合わせる。
  「この状況に自分の思想を入れると、もっと悲惨になるのか」
  「でも、ここは救われている」
  という、割り切れない気持ちが残る。

## 家族の状況：国と統計

- 生まれる国は、**世界の出生数に比例して**選ぶ。
- 家族の状況は、その国の統計から確率で決める。
  - 所得（その国の所得分布のどの層に生まれるか）
  - 平均寿命、乳幼児死亡率
  - 教育（就学率、進学率）
  - 障害の有病率
  - 失業率
  - 婚姻・離婚、出生数（きょうだいの数）
- 人生の偶然の出来事（病気、失業、死別）も、その国の確率で起こす。
- 数字は世界銀行、国連、WHOなどの公開統計を使い、出典をゲーム内に明記する。作り手が数字をつくらない。
- 国の平均だけでは粗いので、少なくとも所得の層は国内の分布から選ぶ。
- 統計がない国や項目は、地域の平均で埋めるなどの扱いを決める。

## 仕組みの考え方（実装ではない）

- **価値観の軸**：回答から複数の軸をつくる。矛盾した回答は「どちらにも引っ張られる不安定な軸」として持つ。不安定な軸がどちらに転ぶかは、そのときのストレスや状況で変わる。
- **出来事**：生まれた状況（お金、地域、健康、家族構成）から起きる。
- **行動**：出来事ごとに、親は自分の思想に従って行動する。その行動が家族のほかの人に影響する。子どもは、親の思想を受け継ぐことも、反発することもある。
- **偶然をそろえる**：失業、病気、出会いなどの偶然の出来事は、二つの人生で同じ年に同じように起こす。違いは、親の判断とその結果からだけ生まれるようにする。
- **分かれ目を見せる**：年表の分岐点に、原因になった回答を添える。
  例：「ここで、あなたの『家族が困っていたら何よりも優先する』という答えが、この人に仕事を辞めさせた」

### 価値観の軸（たたき台）

| 軸 | 矛盾を誘う質問の例 |
|---|---|
| 立ち向かう ⇔ 逃げる | 「苦しいことには、何があっても立ち向かうべき」／「苦しいときは逃げ出してもいい」 |
| 仕事 ⇔ 家族 | 「仕事で結果を出すことが家族を守ること」／「家族が困っていたら何よりも優先する」 |
| 自分でなんとかする ⇔ 頼る | 「人に迷惑をかけてはいけない」／「困ったときは助けを求めるべき」 |
| 平等 ⇔ 実力 | 「世の中は平等であるべきだ」／「努力した人が多く得るのは当然だ」 |
| 安定 ⇔ 挑戦 | 「家族がいるなら冒険はしない」／「後悔しない生き方をしたい」 |
| 我慢する ⇔ 表に出す | 「弱いところは子どもに見せない」／「つらいときはつらいと言っていい」 |
| 道を示す ⇔ 任せる | 「子どもには正しい道を教えるべき」／「子どもの人生は子どもが決める」 |
| 世間 ⇔ 自分の基準 | 「周りにどう見られるかは大事だ」／「人と違っていい」 |

## 守ること

- **プレイヤーの価値観を採点しない。** 結果がどれだけ厳しくても、「あなたの考えが間違っていた」とは言わない。
- **どちらの人生が良かったかを、作品の側で決めない。** 片方がいつも良く見える作りにしない。物差しによって評価が入れ替わるようにする。
- **貧困や障害を、思想の良し悪しへの罰や試練に見せない。** 状況はただ与えられるものとして、敬意を持って描く。
- **幸福をパラメーターで測らない。** 親子の関係も人生の良し悪しも、いつ、誰の目線で、何をもって測るかで変わる。だから数値で判定しない。

---

## 底に置くもの

「あと何回」「最後の日」は作者の思想であり、メインテーマにはしない。
年表の中に、強調も説明もせずに置いておく。感じる人だけが感じればいい。

例：「父と最後に二人で食事をしたのは、41歳の冬だった」
