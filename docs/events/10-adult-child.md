# 大人になった子ども

書き方は [../events.md](../events.md) を参照。

この分野の出来事は、**大人になった子どもが、自分の価値観で判断する**。子どもの価値観は、親から受け継いだもの、親への反発、育った状況が混ざってできている（[design.md](../design.md) の「判断の仕組み」）。

### A01　仕事を選ぶ
- **時期**：子 16〜25歳
- **起きやすさ**：どの国でも。
- **状況**：最初の仕事を選ぶ。
- **選択肢**
  - 親と同じ仕事に就く（伝統＋、同調＋、安全＋）→ 地元に残る。
  - 安定した勤め先を選ぶ（安全＋、達成＋）→ 都市へ出る（5割）。
  - やりたいことを選ぶ（自律＋、刺激＋、安全−）→ 所得は不安定になる。
- **年表**：「親と同じ漁師になった。」

### A02　親元を離れる
- **時期**：子 16〜30歳
- **起きやすさ**：どの国でも。
- **状況**：家を出て、一人で暮らすか。
- **選択肢**
  - 出る（自律＋、刺激＋、伝統−）→ 親と会う頻度が下がる。
  - 親と暮らし続ける（伝統＋、慈善＋、安全＋）→ 親の暮らしを支える。
- **年表**：「二十歳で家を出た。」

### A03　親への仕送り
- **時期**：子 18〜60歳〔条件：子どもが働いている〕
- **起きやすさ**：親への仕送りが当たり前の国ほど。
- **状況**：親から、仕送りを頼まれた。自分の暮らしも楽ではない。
- **選択肢**
  - 送る（慈善＋、伝統＋、快楽−）→ 自分の家計が苦しくなる。
  - 送らない（自律＋、安全＋、伝統−）→ 親との仲がこじれる（3割）。
- **年表**：「毎月、親に仕送りをした。」

### A04　親の反対する結婚
- **時期**：子 18〜35歳
- **起きやすさ**：どの国でも。
- **状況**：結婚したい相手を、親が認めない。
- **選択肢**
  - 押し切って結婚する（自律＋、普遍＋、伝統−）→ 親との縁が切れる（4割）。
  - あきらめる（伝統＋、同調＋）→ 別の相手と結婚する。
  - 説得を続ける（慈善＋、自律＋）→ 認められる（4割）。
- **年表**：「親の反対を押し切って、結婚した。」

### A05　親と同じ道を行くか
- **時期**：子 18〜40歳
- **起きやすさ**：どの国でも。
- **状況**：気づけば、親と同じことをしている自分がいる。
- **選択肢**
  - そのまま続ける（伝統＋、安全＋）→ 親と似た人生になる。
  - 意識して別の道を選ぶ（自律＋、刺激＋、伝統−）→ 親とは違う人生になる。
- **年表**：「親とは違う生き方を選んだ。」

### A06　親を許すか
- **時期**：子 20〜60歳
- **起きやすさ**：親との関係がこじれた場合。
- **状況**：子どもの頃の親の言葉や仕打ちを、今も覚えている。
- **選択肢**
  - 親と話し合う（普遍＋、慈善＋）→ 関係が少し戻る（5割）。
  - 距離を置く（自律＋、安全＋、慈善−）→ 会う頻度が下がる。
  - 何もなかったことにする（伝統＋、同調＋）→ 何も変わらない。
- **年表**：「親とは、年に一度だけ会うことにした。」

### A07　自分の子育て
- **時期**：子 20〜45歳〔条件：子どもに子どもが生まれた〕
- **起きやすさ**：出生率に連動。
- **状況**：自分の子どもを、親が自分を育てたように育てるか。
- **選択肢**
  - 親と同じように育てる（伝統＋、同調＋）→ 親のやり方が受け継がれる。
  - 親とは逆のやり方で育てる（自律＋、普遍＋、伝統−）→ 親とぶつかる（4割）。
- **年表**：「自分の子は、親とは違うやり方で育てた。」

### A08　親の介護
- **時期**：子 30〜65歳〔条件：親に介護が必要〕
- **起きやすさ**：親が年を取ったとき。
- **状況**：親の世話が必要になった。
- **選択肢**
  - 引き取って世話をする（伝統＋、慈善＋、達成−）→ 自分の仕事の時間が減る。
  - 施設に預ける（自律＋、安全＋、伝統−）→ 親と会う頻度が下がる。
  - きょうだいに任せる（達成＋、慈善−）→ きょうだいと疎遠になる（4割）。
- **年表**：「親を引き取り、一緒に暮らした。」

### A09　故郷を出て遠くへ
- **時期**：子 18〜40歳
- **起きやすさ**：移住の多い国ほど。
- **状況**：遠くの都市や外国で、仕事の機会がある。
- **選択肢**
  - 行く（刺激＋、達成＋、伝統−）→ 親と会うのは年に一度以下になる。
  - 残る（伝統＋、慈善＋、安全＋）→ 親の近くで暮らす。
- **年表**：「外国へ渡った。」

### A10　親の期待に応えるか
- **時期**：子 15〜30歳
- **起きやすさ**：どの国でも。
- **状況**：親が、自分に大きな期待をかけている。
- **選択肢**
  - 応えようとする（同調＋、達成＋、慈善＋、自律−）→ 応えられる（4割）。疲れ果てる（3割）。
  - 自分のやり方で生きる（自律＋、同調−）→ 親が落胆する（4割）。
- **年表**：「親の期待どおり、医者になった。」

### A11　実家の家業
- **時期**：子 18〜40歳〔条件：家業がある〕
- **起きやすさ**：自営業の多い国ほど。
- **状況**：親が、家業を継いでほしいと言う。
- **選択肢**
  - 継ぐ（伝統＋、慈善＋、自律−）→ 地元に残る。
  - 継がない（自律＋、刺激＋、伝統−）→ 家業は閉じる（5割）。
- **年表**：「家業は継がなかった。」

### A12　自分が親の年になったとき
- **時期**：子 40〜60歳
- **起きやすさ**：毎年少しずつ。
- **状況**：自分が、親が自分を育てていた年になった。
- **選択肢**
  - 親に連絡を取る（慈善＋、伝統＋）〔条件：親が存命〕→ 親と会う頻度が少し上がる。
  - 何もしない（安全＋）→ 何も変わらない。
- **年表**：「父がこの年だった頃のことを、思い出した。」

### A13　親の財産
- **時期**：子 30〜70歳〔条件：親が亡くなった〕
- **起きやすさ**：親が財産を持っていた場合。
- **状況**：親の残したものを、きょうだいで分ける。
- **選択肢**
  - 等分を求める（普遍＋）→ きょうだいと少しもめる（3割）。
  - 親の面倒を見た分、多く求める（達成＋、権力＋）→ きょうだいと深くもめる（5割）。
  - 譲る（慈善＋、普遍＋、達成−）→ 自分の取り分はなくなる。
- **年表**：「親の家は、妹に譲った。」

### A14　親の思想を受け継ぐか
- **時期**：子 20〜50歳
- **起きやすさ**：どの国でも。
- **状況**：親がよく口にしていた考え方を、自分の子にも言っている自分に気づく。
- **選択肢**
  - そのまま伝える（伝統＋、同調＋）→ 親の価値観が孫に受け継がれる。
  - 言うのをやめる（自律＋、普遍＋）→ 親の価値観は、自分の代で終わる。
- **年表**：「父の口ぐせを、自分の子にも言っていた。」

### A15　親の最期に立ち会う
- **時期**：子 25〜70歳〔条件：親が危篤。子どもは遠くに住んでいる〕
- **起きやすさ**：遠くに住んでいるとき。
- **状況**：親が危ないと連絡が来た。
- **選択肢**
  - すぐに帰る（慈善＋、伝統＋、達成−）→ 間に合う（6割）。
  - 仕事を片付けてから帰る（達成＋、安全＋）→ 間に合わない（6割）。
- **年表**：「親の最期に、間に合わなかった。」

### A16　親と暮らすか、配偶者と暮らすか
- **時期**：子 25〜55歳〔条件：子どもが結婚している。親が年老いている〕
- **起きやすさ**：三世代同居の多い国ほど。
- **状況**：配偶者は、親との同居を嫌がっている。
- **選択肢**
  - 親との同居を選ぶ（伝統＋、慈善＋）→ 配偶者との仲がこじれる（4割）。
  - 配偶者の意見を選ぶ（慈善＋、自律＋、伝統−）→ 親と離れて暮らす。
- **年表**：「妻の反対を押して、母と同居した。」

### A17　親の住む町に帰るか
- **時期**：子 30〜60歳〔条件：親と離れて暮らしている〕
- **起きやすさ**：どの国でも。
- **状況**：親が年を取った。帰ってきてほしいとは言わないが、寂しそうだ。
- **選択肢**
  - 帰る（慈善＋、伝統＋、達成−）→ 仕事を変える。
  - 帰らない（達成＋、自律＋）→ 親と会う頻度は年に数回のまま。
- **年表**：「親の町には、帰らなかった。」

### A18　親に言えなかったこと
- **時期**：子 20〜70歳〔条件：親が存命〕
- **起きやすさ**：毎年少しずつ。
- **状況**：親に、ずっと言えなかったことがある。
- **選択肢**
  - 言う（普遍＋、自律＋）→ 親との関係が変わる。
  - 言わないでおく（安全＋、伝統＋）→ 言わないまま終わる（6割）。
- **年表**：「親には、最後まで言わなかった。」

### A19　自分の子が家を出る
- **時期**：子 40〜60歳〔条件：子どもに子どもがいる〕
- **起きやすさ**：どの国でも。
- **状況**：自分の子が、遠くへ行くと言う。かつて自分が親にそう言ったように。
- **選択肢**
  - 送り出す（自律＋、普遍＋）→ 孫と会う頻度が下がる。
  - 引き止める（伝統＋、安全＋、慈善＋）→ 子が残る（4割）。
- **年表**：「かつて自分がそうしたように、子を送り出した。」

### A20　親の人生を知る
- **時期**：子 30〜70歳
- **起きやすさ**：親が年老いたか、亡くなったあと。
- **状況**：親の昔の手紙や写真が出てきた。知らなかった親の姿がある。
- **選択肢**
  - 親に聞く、または親族に聞いて回る（普遍＋、自律＋）→ 親の人生を知る。
  - そっとしまっておく（伝統＋、安全＋）→ 知らないままになる。
- **年表**：「父の若い頃の手紙を見つけた。」
