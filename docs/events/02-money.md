# お金

書き方は [../events.md](../events.md) を参照。

### M01　高利の借金の誘い
- **時期**：親 18〜65歳
- **起きやすさ**：所得の層が低いほど。銀行を使えない人が多い国ほど。
- **状況**：今月の支払いが足りない。高い利息で、すぐ貸してくれる人がいる。
- **選択肢**
  - 借りる（安全＋、快楽＋、達成−）→ 今月はしのげる。返済が膨らむ（5割）。
  - 持ち物を売る（自律＋、安全＋、伝統−）→ 家財や形見がなくなる。
  - 支払いを待ってもらうよう頭を下げる（同調＋、慈善＋、権力−）→ 待ってもらえる（5割）。
- **年表**：「高い利息で金を借りた。」

### M02　借金の取り立て
- **時期**：親 20〜70歳〔条件：借金がある〕
- **起きやすさ**：借金が重いほど。
- **状況**：取り立てが家まで来るようになった。子どもも見ている。
- **選択肢**
  - 家族に隠して、別の借金で返す（権力＋、安全＋、普遍−）→ 借金が膨らむ（6割）。
  - 家族に打ち明けて、皆で返す（慈善＋、普遍＋、権力−）→ 家族で働く。子どもが学校を休む（3割）。
  - 夜逃げする（自律＋、刺激＋、伝統−）→ 住む場所が変わる。親族との縁が切れる。
  - 公的な救済を申し立てる（普遍＋、安全＋、同調−）〔条件：制度がある国〕→ 借金が減る。周りに知られる。
- **年表**：「取り立てが来るようになり、家族に打ち明けた。」

### M03　詐欺の儲け話
- **時期**：親 25〜80歳
- **起きやすさ**：どの国でも。年を取るほど。
- **状況**：「必ず倍になる」という投資の話を、知り合いが持ってきた。
- **選択肢**
  - 乗る（達成＋、刺激＋、快楽＋、安全−）→ 失う（8割）。
  - 少しだけ乗る（刺激＋、安全＋）→ 小さく失う（8割）。
  - 断る（安全＋、伝統＋）→ 何も起きない。
- **年表**：「投資話に乗り、貯金を失った。」

### M04　貯金をどう使うか
- **時期**：親 25〜60歳〔条件：貯金がある〕
- **起きやすさ**：所得の層が中〜高ほど。
- **状況**：少し貯金ができた。
- **選択肢**
  - 家を建てる、買う（安全＋、伝統＋、達成＋）→ 住まいが安定する。貯金はなくなる。
  - 子どもの教育に取っておく（慈善＋、普遍＋、快楽−）→ 子どもの進学の選択肢が増える。
  - 家族旅行に使う（快楽＋、慈善＋、安全−）→ 家族の思い出が残る。
  - そのまま置いておく（安全＋）→ 何かあったときに使える。
- **年表**：「貯金で家を建てた。」

### M05　家族の高額な治療費
- **時期**：親 20〜70歳
- **起きやすさ**：医療保険が弱い国ほど。
- **状況**：家族の治療に、年収を超える費用がかかると言われた。
- **選択肢**
  - 家や土地を売ってでも払う（慈善＋、伝統−、安全−）→ 治療が受けられる。住まいを失う。
  - 借金して払う（慈善＋、安全−）→ 治療が受けられる。借金が重くなる。
  - 安い治療で済ませる（安全＋、慈善−）→ 回復が遅れる（5割）。
  - 親族や地域に募る（同調＋、慈善＋、権力−）→ 半分ほど集まる（5割）。
- **年表**：「治療費のために土地を売った。」

### M06　結婚の持参金や祝儀
- **時期**：親 40〜65歳〔条件：子どもが結婚する〕
- **起きやすさ**：持参金や盛大な婚礼の習慣がある国ほど。
- **状況**：子どもの結婚に、しきたりどおりの大きなお金がかかる。
- **選択肢**
  - しきたりどおりに出す（伝統＋、同調＋、安全−）→ 借金が増える（5割）。面目は保たれる。
  - 出せる分だけにする（自律＋、安全＋、同調−）→ 相手の家と気まずくなる（4割）。
  - しきたり自体を断る（自律＋、普遍＋、伝統−、同調−）→ 縁談が壊れる（3割）。
- **年表**：「しきたりどおりの婚礼のために、借金をした。」

### M07　相続
- **時期**：親 35〜70歳〔条件：自分の親が亡くなった〕
- **起きやすさ**：自分の親が財産を持っていた場合。
- **状況**：親の遺した財産を、きょうだいで分けることになった。
- **選択肢**
  - 等分を主張する（普遍＋、自律＋）→ きょうだいと少しもめる（3割）。
  - 親の面倒を見た者が多く取るべきだと主張する（達成＋、権力＋、慈善−）→ きょうだいと深くもめる（5割）。
  - 長子や男子に譲る、しきたりに従う（伝統＋、同調＋）→ 自分の取り分が減る。
  - 一番困っているきょうだいに譲る（慈善＋、普遍＋、達成−）→ 自分の取り分がなくなる。
- **年表**：「親の財産は、困っていた弟に譲った。」

### M08　拾ったお金
- **時期**：親 18〜80歳
- **起きやすさ**：まれに。
- **状況**：道で、ひと月分の稼ぎほどのお金が入った財布を拾った。家計は苦しい。
- **選択肢**
  - 届ける（普遍＋、同調＋、快楽−）→ 何も起きない。お礼が来る（2割）。
  - 黙って使う（快楽＋、安全＋、普遍−）→ 家計が一時楽になる。
  - 一部だけ使って届ける（慈善＋、普遍−）→ 発覚する（1割）。
- **年表**：「拾った財布を、届けた。」

- **年表**：「保険に入った。」

### M19　お金のことで夫婦が対立する

- **起きやすさ**：家計が苦しいほど。
- **状況**：お金の使い道で、配偶者と毎晩言い争いになる。
- **選択肢**
  - 自分が家計を握る（権力＋、安全＋、慈善−）→ 争いは減る。配偶者の不満がたまる（5割）。
  - 配偶者に任せる（慈善＋、同調＋、権力−）→ 争いは減る。
  - 別々に管理する（自律＋、普遍＋）→ 争いは減る。家族としてのまとまりが弱くなる（3割）。
- **年表**：「家計は、自分が握ることにした。」

### M20　稼いだお金を誰のために使うか
- **時期**：親 25〜60歳
- **起きやすさ**：どの国でも、毎年少しずつ。
- **状況**：今年は少し余裕がある。
- **選択肢**
  - 自分のために使う（快楽＋、自律＋、慈善−）→ 自分の楽しみが増える。
  - 子どものために使う（慈善＋、達成＋）→ 子どもの習い事や学用品が増える。
  - 年老いた親のために使う（伝統＋、慈善＋）→ 親の暮らしが楽になる。
  - 地域や寄付に使う（普遍＋、同調＋）→ 地域での信頼が増す。
- **年表**：「余ったお金で、親に冷蔵庫を買った。」
