# 子育て

書き方は [../events.md](../events.md) を参照。

### C01　学校に行かせるか、働かせるか
- **時期**：子 10〜15歳
- **起きやすさ**：児童労働の割合、所得の層が低いほど。
- **状況**：子どもが働けば、家計が助かる。
- **選択肢**
  - 学校を続けさせる（達成＋、普遍＋、自律＋、安全−）→ 家計が苦しくなる。子どもの教育の段階が上がる。
  - 働きに出す（安全＋、伝統＋、慈善＋）→ 家計が楽になる。子どもは学校をやめる。
  - 学校に通いながら働かせる（達成＋、安全＋）→ 子どもの成績が落ちる（4割）。
- **年表**：「十三歳で学校をやめ、市場で働きはじめた。」

### C02　進学のための仕送り
- **時期**：子 15〜19歳
- **起きやすさ**：所得の層が低いほど重い。
- **状況**：子どもが、町の上の学校に受かった。学費と下宿代がかかる。
- **選択肢**
  - 借金してでも行かせる（達成＋、慈善＋、安全−）→ 借金が増える。子どもの教育の段階が上がる。
  - あきらめさせる（安全＋、伝統＋）→ 子どもは地元で働く。
  - 子ども自身に稼がせて行かせる（自律＋、達成＋）→ 中退する（4割）。
- **年表**：「借金をして、町の学校へ送り出した。」

### C03　きょうだいの誰に学費を出すか
- **時期**：子 12〜18歳〔条件：子どもが二人以上〕
- **起きやすさ**：所得の層が低いほど。
- **状況**：学費は一人分しか出せない。
- **選択肢**
  - 成績の良い子に（達成＋、権力＋、普遍−）→ その子が上の学校へ。ほかの子は働く。
  - 長子や男子に、しきたりどおり（伝統＋、同調＋、普遍−）→ ほかの子が不満を持つ（4割）。
  - くじや順番で決める（普遍＋）→ 公平だが、伸びる子が伸びないこともある。
  - 誰にも出さない（安全＋、普遍＋）→ 全員が地元で働く。
- **年表**：「学費は、勉強のできる妹に出した。」

### C04　しつけで手を上げるか
- **時期**：子 3〜14歳
- **起きやすさ**：体罰が当たり前の国ほど。
- **状況**：子どもが何度言っても聞かない。
- **選択肢**
  - 手を上げる（権力＋、伝統＋、同調＋、普遍−）→ 子どもは言うことを聞く（5割）。子どもとの距離が開く（3割）。
  - 時間をかけて話す（普遍＋、慈善＋、自律＋）→ 時間がかかる。
  - 放っておく（自律＋、安全＋）→ 子どもは自分で学ぶか、学ばない。
- **年表**：「言うことを聞かない息子に、手を上げた。」

### C05　いじめ
- **時期**：子 6〜16歳
- **起きやすさ**：どの国でも。
- **状況**：子どもが学校でいじめられている。
- **選択肢**
  - 学校に強く抗議する（普遍＋、自律＋、同調−）→ 収まる（4割）。
  - 転校させる（安全＋、慈善＋）〔条件：転校先がある〕→ 子どもは新しい学校へ。
  - 「強くなれ」と言う（権力＋、達成＋、伝統＋、慈善−）→ 子どもが心を閉ざす（4割）。
  - 学校を休ませる（慈善＋、安全＋）→ 子どもの教育が遅れる。
- **年表**：「いじめに抗議し、学校を変えた。」

### C06　子どもが周りと違う
- **時期**：子 8〜20歳
- **起きやすさ**：どの国でも。
- **状況**：子どもの好きなもの、話し方、ふるまいが、周りと違うと言われる。
- **選択肢**
  - 周りに合わせるよう言う（同調＋、伝統＋、自律−）→ 子どもは合わせる（5割）。心を閉ざす（3割）。
  - そのままでいいと言う（自律＋、普遍＋、同調−）→ 子どもは自分のままでいる。周りから浮く（4割）。
  - 何も言わない（安全＋）→ 子どもは一人で抱える。
- **年表**：「『そのままでいい』と言った。」

### C07　子どもの信仰
- **時期**：子 12〜25歳
- **起きやすさ**：信仰が暮らしの中心にある国ほど。
- **状況**：子どもが、家の信仰から離れたいと言う。
- **選択肢**
  - 許さない（伝統＋、権力＋、同調＋、自律−）→ 子どもと衝突する（6割）。
  - 子どもに任せる（自律＋、普遍＋、伝統−）→ 親族から責められる（4割）。
  - 形だけは続けるよう頼む（同調＋、慈善＋）→ 子どもはしぶしぶ従う（5割）。
- **年表**：「家の信仰から離れることを、許さなかった。」

### C08　子どもの進路
- **時期**：子 15〜22歳
- **起きやすさ**：どの国でも。
- **状況**：子どもが、親の望まない道に進みたいと言う。
- **選択肢**
  - 反対して、親の決めた道に進ませる（権力＋、安全＋、伝統＋、自律−）→ 子どもは従う（5割）。家を出る（3割）。
  - 子どもに任せる（自律＋、普遍＋）→ 子どもは自分の道を行く。
  - 条件をつけて認める（安全＋、自律＋）→ 子どもは条件を守る（5割）。
- **年表**：「子どもが選んだ道を、黙って見送った。」

### C09　子どもの結婚相手
- **時期**：子 18〜35歳
- **起きやすさ**：どの国でも。
- **状況**：子どもが連れてきた相手を、どうしても認められない。
- **選択肢**
  - 反対し続ける（権力＋、伝統＋、同調＋）→ 子どもとの縁が切れる（4割）。
  - 認める（自律＋、普遍＋、慈善＋）→ 子どもは結婚する。
  - 親が別の相手を探す（伝統＋、権力＋、自律−）→ 子どもが従う（3割）。
- **年表**：「娘の結婚に、最後まで反対した。」

### C10　子どもが法を犯す
- **時期**：子 13〜25歳
- **起きやすさ**：所得の層が低いほど。治安の悪い地区ほど。
- **状況**：子どもが、盗みに関わったと知った。
- **選択肢**
  - 自分で警察に連れていく（普遍＋、同調＋、慈善−）→ 子どもは罰を受ける。親子の関係が揺らぐ。
  - かばう（慈善＋、普遍−）→ また繰り返す（4割）。
  - 家の中で厳しく罰する（権力＋、伝統＋）→ 子どもは家を出る（3割）。
  - 一緒に謝りに行く（慈善＋、普遍＋）→ 相手が許す（5割）。
- **年表**：「息子と一緒に、盗んだ店に謝りに行った。」

### C11　子どもが家を出たいと言う
- **時期**：子 15〜22歳
- **起きやすさ**：どの国でも。
- **状況**：子どもが、遠くの町で一人暮らしをしたいと言う。
- **選択肢**
  - 送り出す（自律＋、普遍＋、慈善−）→ 子どもと会う頻度が下がる。
  - 引き止める（安全＋、伝統＋、慈善＋）→ 子どもは家に残る（5割）。黙って出ていく（3割）。
- **年表**：「十八歳の春、子どもを送り出した。」

### C12　子どもの将来の仕事
- **時期**：子 12〜20歳
- **起きやすさ**：どの国でも。
- **状況**：親として、子どもにどんな仕事に就いてほしいか、口にするかどうか。
- **選択肢**
  - 安定した仕事を勧める（安全＋、同調＋）→ 子どもはそちらに進む（5割）。
  - 家業を継がせる（伝統＋、権力＋）〔条件：家業がある〕→ 子どもは地元に残る（5割）。
  - 好きな道に進めと言う（自律＋、刺激＋）→ 子どもは自分で選ぶ。
- **年表**：「『好きな道に進め』と言った。」

### C13　子どもの性別による扱い
- **時期**：子 6〜18歳
- **起きやすさ**：性別による教育や役割の差が大きい国ほど。
- **状況**：娘と息子、どちらに何を期待するか、周りのしきたりがある。
- **選択肢**
  - しきたりどおりに分ける（伝統＋、同調＋、普遍−）→ 娘は家のことを、息子は外の仕事を任される。
  - 同じように育てる（普遍＋、自律＋、伝統−）→ 周りから言われる（国による）。
- **年表**：「娘にも、息子と同じように学校を続けさせた。」

### C14　子どもの病気と学校
- **時期**：子 6〜16歳〔条件：子どもに障害か長い病気がある〕
- **起きやすさ**：障害の有病率、教育の受け入れの整い方に連動。
- **状況**：近くの学校は、子どもを受け入れたがらない。
- **選択肢**
  - 受け入れるよう学校に求め続ける（普遍＋、自律＋、同調−）→ 受け入れられる（4割）。
  - 遠くの専門の学校に通わせる（慈善＋、安全＋）→ 通学の負担が大きい。
  - 家で育てる（伝統＋、安全＋）→ 子どもの世界が狭くなる。
- **年表**：「受け入れを渋る学校に、通い続けて頼んだ。」

### C15　子どもにお金の苦労を話すか
- **時期**：子 8〜18歳
- **起きやすさ**：家計が苦しいとき。
- **状況**：家計が厳しい。子どもは気づいていない。
- **選択肢**
  - 正直に話す（普遍＋、慈善＋、権力−）→ 子どもが早く大人になる。
  - 隠し通す（権力＋、慈善＋、安全＋）→ 子どもは知らないまま育つ。親の負担が増える。
- **年表**：「家計のことは、子どもに話さなかった。」

### C16　子どもの夢
- **時期**：子 10〜20歳
- **起きやすさ**：どの国でも。
- **状況**：子どもに、才能があるかもしれない夢がある。続けるにはお金がかかる。
- **選択肢**
  - 家計を削って応援する（慈善＋、刺激＋、達成＋、安全−）→ 子どもが伸びる（3割）。家計が苦しくなる。
  - 現実を見るよう言う（安全＋、同調＋）→ 子どもはあきらめる（6割）。
  - 子どもに自分で稼がせる（自律＋、達成＋）→ 続けられる（4割）。
- **年表**：「家計を削って、娘の音楽を続けさせた。」

### C17　子どもと過ごす時間
- **時期**：子 0〜15歳
- **起きやすさ**：どの国でも、毎年少しずつ。
- **状況**：仕事か、子どもとの時間か。今年はどちらに重心を置くか。
- **選択肢**
  - 仕事に重心を置く（達成＋、権力＋、安全＋）→ 所得が上がる。子どもと過ごす時間が減る。
  - 子どもとの時間に重心を置く（慈善＋、快楽＋、達成−）→ 所得は上がらない。
- **年表**：「子どもが寝たあとに帰る日が続いた。」

### C18　子どもの反抗
- **時期**：子 12〜18歳
- **起きやすさ**：どの国でも。
- **状況**：子どもが口をきかなくなり、夜遅くまで帰ってこない。
- **選択肢**
  - 門限を決めて厳しく守らせる（権力＋、安全＋、伝統＋）→ 反発が強まる（5割）。
  - 待つ（自律＋、慈善＋）→ 自然に落ち着く（5割）。
  - 話し合いの場をつくる（普遍＋、慈善＋）→ 話してくれる（4割）。
- **年表**：「門限を決めた。息子は守らなかった。」

### C19　子どもを預けるか
- **時期**：子 0〜6歳
- **起きやすさ**：保育の整い方に連動。
- **状況**：働きに出るには、子どもを誰かに預けなければならない。
- **選択肢**
  - 祖父母や親族に預ける（伝統＋、慈善＋）〔条件：親族が近くにいる〕→ 子どもは祖父母に懐く。
  - 保育施設に預ける（自律＋、達成＋）〔条件：施設がある〕→ 費用がかかる。
  - 働きに出ず、自分で見る（慈善＋、伝統＋、達成−）→ 所得が下がる。
  - 上の子に見させる（安全＋、伝統＋、普遍−）〔条件：上の子がいる〕→ 上の子が学校を休みがちになる。
- **年表**：「下の子の世話を、十歳の長女に任せた。」

### C20　子どもの間違いを認めるか
- **時期**：子 6〜20歳
- **起きやすさ**：どの国でも。
- **状況**：親が子どもを強く叱ったが、実は子どもは悪くなかったと分かった。
- **選択肢**
  - 謝る（普遍＋、慈善＋、権力−）→ 子どもとの信頼が深まる。
  - 謝らない（権力＋、伝統＋）→ 子どもは何も言わない。
- **年表**：「間違って叱ったことを、謝らなかった。」
