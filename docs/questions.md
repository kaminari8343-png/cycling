# 診断の質問（第2稿：はしご形式）

軸と16タイプの考え方は [design.md](design.md) を参照。

---

## 形式

一場面を一回ずつ聞く「点」の質問はやめる。各軸を、次の二種類で構成する。

1. **信念**（4問）：その人が、言葉で信じていること。4段階で答える。
2. **はしご**（3本）：一つの状況を5段階で少しずつ悪化させ、**どの段で答えが変わるか（境目）**を取る。3本のはしごは、同じ状況を別の相手や別の場面に置き換えたもの。

### はしごの答え方

- 段を一つずつ見せる。各段で、左の行動を続けるか、右の行動に変えるかを選ぶ。
- 右に変えた段で止める。その段が**境目**。
- 5段目まで変わらなければ、境目は「変えない」。
- 境目の記録：1段目〜5段目＝1〜5、変えない＝6。境目が早いほど右に寄る。

### そこから取れるもの

- **向きと強さ**：信念の点数と、3本の境目の平均から出す。
- **揺らぎ**：信念の両側に、どちらも「そう思う」と答えている度合い。
- **ずれ**（「あなたの矛盾」の材料）
  - **はしご同士のずれ**：自分・子ども・他人で、境目が2段以上離れている。
  - **信念とはしごのずれ**：右側の信念に強くうなずいているのに、境目が4段目以降（またはその逆）。

## 軸1　立ち向かう ⇔ 降りる

**信念**
- 苦しいことには、何があっても立ち向かうべきだ。（左）
- 一度始めたことは、最後までやり通すべきだ。（左）
- 苦しいときは、逃げ出してもいい。（右）
- 逃げることも、立派な選択だ。（右）

**はしご①　自分**　職場がつらい。続ける？ 辞める？
1. 仕事が合わないと感じる
2. 毎日、上司に怒鳴られる
3. 眠れなくなってきた
4. 朝、体が動かない日がある
5. 医者に「休んだほうがいい」と言われた

**はしご②　子ども**　子どもが「学校に行きたくない」と言う。行かせる？ 休ませる？
1. 理由は言わない
2. 一週間続いている
3. 友だちから無視されていると分かった
4. 朝、お腹が痛いと言って泣く
5. 夜、眠れていない

**はしご③　他人**　友人が「仕事を辞めたい」と相談してきた。「続けろ」と言う？ 「辞めていい」と言う？
1. 仕事が合わないと言う
2. 毎日、上司に怒鳴られているらしい
3. 眠れなくなってきたらしい
4. 朝、体が動かない日があるらしい
5. 医者に「休んだほうがいい」と言われたらしい

## 軸2　稼ぐ ⇔ そばにいる

**信念**
- 仕事で結果を出すことが、家族を守ることだ。（左）
- 働く背中を見せることも、立派な子育てだ。（左）
- 家族が困っていたら、何よりも優先する。（右）
- 貧しくても、毎晩いっしょに夕飯を食べられる家がいい。（右）

**はしご①　自分**　今の働き方を続ける？ 仕事を減らす（収入は3割減る）？
1. 子どもに「最近遊んでくれない」と言われる
2. 子どもの成績が落ちてきた
3. 配偶者に「一人ではもう限界」と言われる
4. 子どもが学校で問題を起こした
5. 子どもに「家にいたくない」と言われた

**はしご②　子ども**　大人になった子どもが、仕事で家族と過ごせていない。「今の働き方を続けなさい」と言う？ 「仕事を減らしなさい」と言う？
1. 孫が「最近遊んでくれない」と言っている
2. 孫の成績が落ちてきた
3. 子どもの配偶者が「一人ではもう限界」と言っている
4. 孫が学校で問題を起こした
5. 孫が「家にいたくない」と言った

**はしご③　他人**　同僚が同じ状況にいる。「今の働き方を続けたほうがいい」と言う？ 「仕事を減らしたほうがいい」と言う？
（段は①と同じ）

## 軸3　自力 ⇔ 頼る

**信念**
- 人に迷惑をかけてはいけない。（左）
- 自分の問題は、自分で解決するのが大人だ。（左）
- 困ったときは、助けを求めるべきだ。（右）
- 子どもには、人に頼れる大人になってほしい。（右）

**はしご①　自分**　お金が苦しい。自分でなんとかする？ 親戚や国の制度に助けを求める？
1. 今月の家賃が少し足りない
2. 二か月続けて足りない
3. 借金が月収を超えた
4. 電気を止められた
5. 子どもの食事を減らしはじめた

**はしご②　子ども**　大人になった子どもが、同じ状況にいる。「自分でなんとかしなさい」と思う？ 「助けを求めなさい」と思う？
（段は①と同じ）

**はしご③　他人**　近所の家族が、同じ状況にいる。「自分たちでなんとかするべきだ」と思う？ 「助けを求めるべきだ」と思う？
（段は①と同じ）

## 軸4　平等 ⇔ 実力

この軸のはしごは、相手ではなく**場**を変える。家の中・職場・社会の三つ。

**信念**
- 世の中は平等であるべきだ。（左）
- 生まれた場所で人生が決まるのは、おかしい。（左）
- 努力した人が多く得るのは当然だ。（右）
- 競争がなければ、人は怠ける。（右）

**はしご①　家の中**　子ども二人の学費。二人に同じだけ出す？ 上の子に多く出す？
1. 上の子のほうが、少し成績がいい
2. 上の子は毎日勉強する。下の子はしない
3. 上の子は奨学金の候補。下の子は赤点が続いている
4. 二人分を同じだけ出すと、どちらも十分な学校には行けない
5. 下の子に出しても、卒業できそうにない

**はしご②　職場**　同じ仕事をする同僚二人。給料は同じにするべき？ 差をつけるべき？
1. 片方のほうが、少し手際がいい
2. 片方は、もう片方の倍の仕事をこなす
3. 片方は残業してでも仕上げる。もう片方は定時に帰る
4. もう片方のミスを、片方が毎回直している
5. もう片方は、仕事中にほとんど何もしていない

**はしご③　社会**　貧しい家族への援助。続けるべき？ 打ち切るべき？
1. 働いているが、それでも貧しい
2. 働きたいが、仕事が見つからない
3. 働ける体だが、条件の合う仕事しかしない
4. 何年も援助を受け続けている
5. 援助のお金で、酒や賭け事をしているらしい

## 軸5　安定 ⇔ 挑戦

この軸のはしごは、悪化ではなく**成功の見込み**を上げていく。どこまで見込みがあれば踏み出すか。

**信念**
- 家族がいるなら、冒険はしないものだ。（左）
- 安定した勤め先がいちばんだ。（左）
- 後悔しない生き方をしたい。（右）
- 失敗しても、やらないよりはいい。（右）

**はしご①　自分**　夢だった店を開ける話が来た。貯金は全部なくなる。今の仕事を続ける？ 店を開く？
1. 成功する見込みは、1割
2. 3割
3. 半分
4. 7割
5. 9割

**はしご②　子ども**　子どもが「学校をやめて、音楽で食べていく」と言った。止める？ 応援する？
（成功の見込みの段は①と同じ）

**はしご③　他人**　友人が、会社を辞めて起業すると言う。止める？ 応援する？
（成功の見込みの段は①と同じ）

## 軸6　我慢する ⇔ 表に出す

**信念**
- 弱いところは、子どもに見せないほうがいい。（左）
- 大人は、感情で動いてはいけない。（左）
- つらいときは、つらいと言っていい。（右）
- 子どもには、つらいときに「つらい」と言える人になってほしい。（右）

**はしご①　自分**　あなたがつらい。黙っている？ 家族に話す？
1. 仕事で嫌なことがあった
2. 一週間、よく眠れていない
3. 理由もなく涙が出ることがある
4. 何をしても楽しくない日が続いている
5. 朝、起き上がるのがやっとだ

**はしご②　子ども**　子どもが同じ状態にいる。「黙っていてもいい」と思う？ 「親に話してほしい」と思う？
（段は①と同じ）

**はしご③　他人**　同僚が同じ状態にいる。「黙っていてもいい」と思う？ 「周りに話すべきだ」と思う？
（段は①と同じ）

## 軸7　導く ⇔ 任せる

この軸のはしごは、**選択の危うさ**を上げていく。どこから口を出すか。境目が早いほど左（導く）に寄る。

**信念**
- 子どもには、正しい道を教えるべきだ。（左）
- 親の言うことを聞くのは、子どもの務めだ。（左）
- 子どもの人生は、子どもが決めるものだ。（右）
- 失敗すると分かっていても、黙って見守るべきときがある。（右）

**はしご①　自分の子ども**　子どもが、あなたの反対することを選んだ。見守る？ 止めに入る？
1. あなたが勧めない部活を選んだ
2. あなたが反対する学校に進むと言う
3. 先の見えない仕事を選んだ
4. あなたが認めない相手と結婚すると言う
5. 借金をして事業を始めると言う

**はしご②　自分と親**　あなた自身が、親の反対することを選んだ。親に口を出されても仕方ないと思うのは、何段目から？
（段は①と同じ。「あなたが」を「あなたの親が」に置き換える）

**はしご③　他人**　知り合いの家の子どもが、親の反対することを選んだ。その親は、見守るべき？ 止めに入るべき？
（段は①と同じ）

## 軸8　世間・伝統 ⇔ 自分の基準

この軸のはしごは、**周りから受ける代償**を上げていく。どこまでなら自分のやり方を通すか。

**信念**
- 周りにどう見られるかは、大事だ。（左）
- 昔からの習わしには、意味がある。（左）
- 人と違っていい。（右）
- 正しいと思うなら、周りが全員反対してもやる。（右）

**はしご①　自分**　あなたは、地域や家の習わしと違う生き方を選んだ。周りに合わせる？ 自分のやり方を通す？
1. 近所で少し噂される
2. 親戚に会うたび小言を言われる
3. 職場で浮いてしまう
4. 親に「恥ずかしい」と言われる
5. 仕事を失うかもしれない

**はしご②　子ども**　子どもが、周りと違う生き方を選んだ。合わせるよう言う？ そのままでいいと言う？
（段は①と同じ）

**はしご③　他人**　近所の人が、周りと違う生き方を選んだ。合わせるべきだと思う？ そのままでいいと思う？
（段は①と同じ）

## 軸9　今 ⇔ 将来

この軸のはしごは、**将来のための我慢**を重くしていく。どこまでなら将来を優先するか。境目が早いほど左（今）に寄る。

**信念**
- 今日を楽しく生きることが、いちばん大事だ。（左）
- 明日どうなるか分からないなら、今を大事にするべきだ。（左）
- 将来のために、今を我慢するのは当然だ。（右）
- 老後のために、若いうちから備えるべきだ。（右）

**はしご①　自分**　将来のために、ここまで我慢する？
1. 外食をやめる
2. 旅行をやめる
3. 休日も働く
4. 食事を減らす
5. 体調を崩しても続ける

**はしご②　子ども**　子どもの将来のために、子どもにここまで我慢させる？
1. 遊ぶ時間を減らさせる
2. 友だちと出かけるのを減らさせる
3. 休日も勉強させる
4. 寝る時間を削って勉強させる
5. 体調を崩しても続けさせる

**はしご③　家計**　子どもが働けば、家計が助かる。それでも学校を続けさせる？
1. 家計に少し余裕がなくなる
2. 毎月、少し足りない
3. 借金をしないと学費が払えない
4. 下の子の食事が減る
5. 家族の誰かが病気でも、薬が買えない

## 軸10　家族の内 ⇔ 外

この軸のはしごは、**相手との距離**を遠くしていく。どこまでの人なら助けるか。境目が早いほど左（内）に寄る。家計が苦しいことを前提にする。

**信念**
- まず自分の家族を守れなければ、他人は助けられない。（左）
- 稼いだお金は、まず自分の家族のために使う。（左）
- 困っている人がいたら、見ず知らずでも助けるべきだ。（右）
- 地域や国のために働くことは、家族のために働くことと同じくらい大事だ。（右）

相手の段（三本とも共通）
1. 自分のきょうだい
2. いとこ
3. 近所の家族
4. 同じ国の、見知らぬ人
5. 遠い国の、見知らぬ人

**はしご①　お金**　苦しい家計から、月の収入の1割を出す？
**はしご②　時間**　自分の休日を、毎週その人のために使う？
**はしご③　危険**　自分の身に危険がおよぶかもしれない場面で、その人を助けに行く？

## 軸をまたぐ質問

**順位①**　大切な順に並べて。
お金／健康／家族／自由／誇り

**順位②**　子どもに一つだけ残せるなら、大切な順に並べて。
お金／学歴／健康な体／信じるもの／帰れる家

**はしご　親の介護**　親の介護が必要になった。仕事を続けて施設や親族に頼る？ 仕事を辞めて自分で介護する？（軸2・軸3）
1. 物忘れが増えた
2. 一人で外出すると、帰り道が分からなくなる
3. 夜中に何度も起きて、家の中を歩き回る
4. あなたの名前を、ときどき忘れる
5. あなたのことを、もう分からない

**選択**　子どもに、いちばん言われたくない言葉は？
「放っておいて」／「あなたみたいにはなりたくない」／「なんで助けてくれなかったの」／「普通の家がよかった」
（シミュレーションの中で、子どもが実際に口にしうる言葉としても使う）

**二択**　人生をやり直せるなら、今と同じ道を選ぶ？
はい／いいえ

## 「あなたの矛盾」の作り方

### はしご同士のずれ

三本の境目を並べ、2段以上離れていれば出す。

例（軸1）：自分＝2段目、子ども＝4段目、他人＝1段目
> あなたは、自分の仕事は**2段目**で辞めていいと思っています。友人には**1段目**で「辞めていい」と言います。でも子どもには、**4段目**まで学校に行かせます。
> **他人には逃げ道を、自分には少しの我慢を、子どもには一番の我慢を。**

軸ごとの型（ずれの向きで言い回しを選ぶ）

| 軸 | ずれ | 一言 |
|---|---|---|
| 1 | 子どもの境目が、自分より遅い | 自分は降りるのに、子どもには立ち向かわせる。 |
| 2 | 子ども・他人の境目が、自分より早い | 人には家族を勧めるのに、自分は働き続ける。 |
| 3 | 自分の境目が、子ども・他人より遅い | 自分は誰にも頼らないのに、人には頼れと言う。 |
| 4 | 社会の境目が遅く、家の中の境目が早い | 世界には平等を、家の中では選別を。 |
| 5 | 自分の境目が、子どもより早い | 自分には夢を、子どもには安定を。 |
| 6 | 自分の境目が遅く、子どもの境目が早い | 泣き方を見せないまま、泣いていいと教える。 |
| 7 | 親からは口を出されたくないのに、子どもには早く口を出す | されて嫌だったことを、子どもにはする。 |
| 8 | 自分の境目が遅く、子どもの境目が早い | 自分は人と違っていいのに、子どもには周りに合わせろと言う。 |
| 9 | 自分の境目が早く、子どもの境目が遅い | 自分は今を生き、子どもには将来を背負わせる。 |
| 10 | 時間・危険の境目が、お金より早い | お金は遠くまで届くのに、手は家族にしか届かない。 |

### 信念とはしごのずれ

信念で一方の側に「とてもそう思う」と答えたのに、はしごでは反対側の行動をしている場合に出す。

例（軸2）：「家族が困っていたら、何よりも優先する」に**とてもそう思う**。でも、はしご①の境目は**変えない**（5段目まで働き方を続ける）。
> 家族がいちばんだと、あなたは言いました。でも子どもに「家にいたくない」と言われても、働き方は変えませんでした。

### ずれが一つもない人

揺らぎが最も大きい軸を使う。
> あなたは「苦しいことには立ち向かうべき」と「逃げ出してもいい」の両方に、とてもそう思うと答えました。追い詰められたとき、どちらのあなたが出てくるのかは、まだ誰も知りません。

## 出し方

- 信念40問は混ぜて出す。同じ軸の左右の信念は、間に10問以上はさむ。
- はしごは、信念の間に一本ずつはさむ。同じ軸の三本は続けて出さない。
- 信念の点数：とてもそう思う＝2、そう思う＝1、そう思わない＝−1、まったく思わない＝−2（その信念の向きに加算）。
- はしごの点数：境目1〜6を、右寄り＋2〜左寄り−2に読み替える（1＝＋2、2＝＋1、3＝0、4＝−1、5〜6＝−2）。軸7、9、10は、境目が早いほど左に寄るため符号を反転する。
- 全体の数：信念40問、はしご31本（各軸3本＋介護）、順位2問、選択1問、二択1問。
