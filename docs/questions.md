# 診断の質問（第3稿：上の段の価値観）

## 方針

- 子ども、仕事、学校のような**生活の場面は、診断には出さない**。子どもがいない人、仕事をしていない人、学校に通っていない人にも答えられるようにする。
- 測るのは、その人が**何を大事にして生きているか**という上の段の価値観だけ。
- 個別の場面（出稼ぎ、学費、介護など）でどう判断するかは、シミュレーションの側で、この価値観から決める。
- 土台は、シュワルツの基本的価値観理論の10の価値。研究で使われている質問紙（PVQ）の文面は使わず、この作品用に書いた質問を使う。

---

## 10の価値

10の価値は円の形に並び、隣り合う価値は両立しやすく、向かい合う価値は両立しにくい。

| 価値 | 何を大事にするか |
|---|---|
| 自律 | 自分で考え、自分で決める |
| 刺激 | 変化、驚き、冒険 |
| 快楽 | 楽しむこと、心地よさ |
| 達成 | 成功し、認められること |
| 権力 | 人の上に立つこと、財産、支配 |
| 安全 | 安心、秩序、守られていること |
| 同調 | 決まりを守り、周りに合わせること |
| 伝統 | 受け継がれたもの、しきたり、信仰 |
| 慈善 | 身近な人の幸せ、仲間への誠実さ |
| 普遍主義 | すべての人の平等、公正、自然 |

**大きな二軸**
- **変化への開放 ⇔ 保守**：自律・刺激（・快楽） ⇔ 安全・同調・伝統
- **自分を高める ⇔ 自分を超える**：達成・権力（・快楽） ⇔ 慈善・普遍主義

**向かい合う組**（両方を強く大事にしていれば、構造的な矛盾）
- 権力 ⇔ 普遍主義
- 達成 ⇔ 慈善
- 自律 ⇔ 同調
- 自律 ⇔ 伝統
- 刺激 ⇔ 安全
- 快楽 ⇔ 伝統

## 第一部：人物描写（60問）

「こういう人は、あなたにどれくらい似ていますか？」
答え：とても似ている／似ている／あまり似ていない／まったく似ていない

### 自律
1. 自分の考えで物事を決めることを、大切にしている人。
2. 人に指図されず、自分のやり方で進みたい人。
3. 新しいことを考え出し、工夫するのが好きな人。
4. 何を信じるかは、自分で決めたい人。
5. 分からないことは、自分で確かめないと気がすまない人。
6. 誰にも頼らず、自分の力で立っていたい人。

### 刺激
1. 驚きや変化のある毎日を求めている人。
2. 退屈が、何よりも苦手な人。
3. 危なくても、心が躍ることをしてみたい人。
4. 同じ場所に長くいると、どこかへ行きたくなる人。
5. 誰もやったことのないことに、惹かれる人。
6. 平穏より、刺激のある人生を選びたい人。

### 快楽
1. 楽しむことを、人生でいちばん大事にしている人。
2. おいしいものや心地よいことに、時間とお金を使いたい人。
3. 我慢するより、今を楽しみたい人。
4. 自分を甘やかすことに、罪悪感がない人。
5. 楽しくないことは、できるだけしたくない人。
6. 人生は、楽しんだもの勝ちだと思っている人。

### 達成
1. 人から認められるような成功を、手に入れたい人。
2. 自分の力を示すことが、大切だと思っている人。
3. 目標を立てて、それをやり遂げることに喜びを感じる人。
4. 人より上手にできることがあると、誇らしく思う人。
5. 結果を出せない自分を、許せない人。
6. 野心を持つことは、良いことだと思っている人。

### 権力
1. 人の上に立ち、周りを動かしたい人。
2. お金や財産を持つことが、大事だと思っている人。
3. 自分の言うことに人が従ってくれると、気分がいい人。
4. 決められる側ではなく、決める側にいたい人。
5. 力のない者は、力のある者に従うべきだと思っている人。
6. 好かれるより、恐れられるほうがいいと思うことがある人。

### 安全
1. 安心して暮らせることを、何より大事にする人。
2. 危ないことは、できるだけ避けたい人。
3. 秩序が保たれていることが、大切だと思っている人。
4. 先の見通しが立たないと、不安になる人。
5. 自分と身内を守るためなら、多少のことには目をつむる人。
6. 強いものに守られていたい人。

### 同調
1. 決まりは、守るべきだと思っている人。
2. 周りに迷惑をかけないことを、大事にしている人。
3. 目上の人には、従うべきだと思っている人。
4. 人から変に思われることを、避けたい人。
5. 自分の意見より、場の空気を優先することがある人。
6. わがままを言わず、控えめでいることが美徳だと思う人。

### 伝統
1. 昔から受け継がれてきたやり方を、守りたい人。
2. 信じているものや、しきたりを大切にしている人。
3. 与えられたもので満足するべきだと思っている人。
4. 先祖や、生まれた土地とのつながりを大事にしている人。
5. 新しいものより、変わらないものに価値を感じる人。
6. 人にはそれぞれ、役割や分というものがあると思う人。

### 慈善
1. 身近な人の役に立つことに、喜びを感じる人。
2. 仲間や身内のためなら、自分を後回しにできる人。
3. 信頼してくれる人を、決して裏切りたくない人。
4. 困っている知り合いを、放っておけない人。
5. 身近な人を許し、受け入れることを大事にしている人。
6. 自分の周りの人が幸せなら、それでいいと思える人。

### 普遍主義
1. 世界中のすべての人が、等しく扱われるべきだと思う人。
2. 自分と違う考えの人の話も、聞くべきだと思う人。
3. 自然や環境を守ることが、大切だと思っている人。
4. 会ったこともない人の不幸にも、心を痛める人。
5. 不正や差別を見ると、黙っていられない人。
6. 弱い立場の人を守ることが、社会の役目だと思う人。

## 第二部：どちらかしか選べないなら（12問）

言葉では両方を大事にしていても、選ぶときにはどちらかを取る。そのずれを拾う。

| # | 選択肢A | 選択肢B | 効く価値 |
|---|---|---|---|
| 1 | 自由に生きる | 安心して生きる | 自律 ⇔ 安全 |

| 3 | 自分が勝つ | 身近な人を勝たせる | 達成 ⇔ 慈善 |
| 4 | 今を楽しむ | しきたりを守る | 快楽 ⇔ 伝統 |
| 5 | 知らない世界へ行く | 慣れた場所にいる | 刺激 ⇔ 安全 |
| 6 | 自分の信じる道を行く | 周りと足並みをそろえる | 自律 ⇔ 同調 |
| 7 | 身近な一人を救う | 見知らぬ十人を救う | 慈善 ⇔ 普遍主義 |

## 第三部：順位（1問）

人生で大切なものを、順に並べてください。
自由／安心／成功／愛／正しさ
（自由＝自律、安心＝安全、成功＝達成、愛＝慈善、正しさ＝普遍主義）

## 点数のつけ方

- 人物描写：とても似ている＝3、似ている＝2、あまり似ていない＝1、まったく似ていない＝0。価値ごとに6問の平均を取る。
- 人によって全体に高くつける・低くつける癖があるので、10の価値の平均を引いて、相対的な値にする（シュワルツの理論での標準的な扱い）。
- 二択：選んだ側の価値に加点する。
- 順位：1位＝2、2位＝1、5位＝−1を、対応する価値に加える。
- 大きな二軸：それぞれの側に含まれる価値の平均の差。

## 「あなたの矛盾」の作り方

### 向かい合う価値を、両方とも強く大事にしている

| 組 | 一言 |
|---|---|
| 権力 ⇔ 普遍主義 | 平等を語りながら、上に立ちたい。 |
| 達成 ⇔ 慈善 | 人のために生きたいのに、人より先に行きたい。 |
| 自律 ⇔ 同調 | 自分の道を行きたいのに、はみ出すのが怖い。 |
| 自律 ⇔ 伝統 | 縛られたくないのに、受け継いだものは手放せない。 |
| 刺激 ⇔ 安全 | 冒険に憧れながら、扉には鍵をかける。 |
| 快楽 ⇔ 伝統 | 今を楽しみたいのに、掟も捨てられない。 |

### 言葉と選択のずれ

人物描写では両方に「似ている」と答えたのに、二択では毎回同じ側を選んでいる。

例：自律にも安全にも「とても似ている」と答えた。でも二択の1、5、10では、毎回安心のほうを選んだ。
> 自由でいたいと、あなたは言いました。でも、どちらかを選ぶときは、いつも安心を選びました。

### 矛盾が見つからない人

価値の差が最もはっきりしている組を使う。
> あなたは迷いなく、自由を選び、安心を捨てる人です。その迷いのなさが、誰かの人生に入ったとき、どう働くかはまだ分かりません。

---

## 出し方

- 人物描写60問は、価値ごとにまとめず混ぜて出す。
- 向かい合う価値の質問を、続けて出さない。
- 二択は、人物描写の合間に少しずつはさむ。
- 順位は最後に出す。
