# 診断の質問（第1稿）

全100問。10軸×9問の90問と、軸をまたぐジレンマ・続きもの・順位づけの10問。
軸と16タイプの考え方は [design.md](design.md) を参照。

---

## 記号の読み方

**軸の向き**：各軸の左側を「左」、右側を「右」と呼ぶ。

| # | 左 | 右 |
|---|---|---|
| 1 | 立ち向かう | 降りる |
| 2 | 稼ぐ | そばにいる |
| 3 | 自力 | 頼る |
| 4 | 平等 | 実力 |
| 5 | 安定 | 挑戦 |
| 6 | 我慢する | 表に出す |
| 7 | 導く | 任せる |
| 8 | 世間・伝統 | 自分の基準 |
| 9 | 今 | 将来 |
| 10 | 家族の内 | 外 |

**種類**
- **信念**：4段階で答える（とてもそう思う／そう思う／そう思わない／まったく思わない）。「そう思う」側がどちらの向きに寄るかを「向き」の列に書く。
- **二択**：どちらかを選ぶ。選択肢ごとに向きを書く。
- **ジレンマ**：3〜4択。選択肢ごとに、複数の軸に効く。
- **続きもの**：前の答えによって、次の状況が変わる。
- **順位**：並べ替え。

**その他の印**
- **矛**：同じ軸の両側から聞く組。両方に「そう思う」と答えると、その軸の揺らぎになる。
- **二重**：自分や他人には一つの基準、身内には別の基準、という二重基準を拾う組。「あなたの矛盾」の材料にする（下の「二重基準の組」）。
- **シミュ**：シミュレーションの中で、親が実際に直面しうる場面。診断での答えが、そのまま親の判断の根拠になる。

## 軸をまたぐ質問（10問）

**X-1　順位**　大切な順に並べてください。
お金／健康／家族／自由／誇り
- 上位に「お金」→ 軸2左、軸9右
- 上位に「家族」→ 軸2右、軸10左
- 上位に「自由」→ 軸5右、軸8右
- 上位に「誇り」→ 軸1左、軸6左

**X-2　ジレンマ**　家族の誰かが、罪を犯したと知った。
- 通報する → 軸10右、軸8左
- かばう → 軸10左
- 自首するよう説得する → 軸7左、軸1左
- 関わらない → 軸1右

**X-3　続きもの**　子どもが学校に行きたくないと言う（1-7の続き）。
- 1-7で「休ませる」→ 1か月たっても行かない。
  - 学校を変える → 軸5右
  - 家で自分が勉強を見る → 軸3左
  - もう少し待つ → 軸7右
  - 無理にでも行かせる → 軸1左、軸7左
- 1-7で「行かせる」→ 子どもが部屋から出てこなくなった。
  - 専門家に相談する → 軸3右
  - 自分で話を聞く → 軸3左、軸6右
  - しばらく放っておく → 軸7右
  - 引きずってでも連れていく → 軸1左、軸7左

**X-4　ジレンマ**　親が倒れて、介護が必要になった。
- 仕事を辞めて自分が介護する → 軸2右、軸3左
- 施設に預ける → 軸3右、軸2左
- きょうだいに頼む → 軸3右
- お金を送って、近くの親族に任せる → 軸2左、軸10左

**X-5　ジレンマ**　子どもがいじめられている。相手は地元の有力者の子ども。
- 学校に強く抗議する → 軸1左、軸8右
- 転校させる → 軸1右
- 子どもに、もう少し耐えるよう言う → 軸6左、軸8左
- 相手の家に直接行く → 軸1左、軸3左

**X-6　ジレンマ**　食べ物は明日の分しかない。子どもの薬代も要る。
- 薬を買う → 軸9右
- 食べ物を買う → 軸9左
- 近所に借りる → 軸3右
- 自分が食べる分を抜いて、両方なんとかする → 軸6左、軸3左

**X-7　続きもの**　2-6で「行く」と答えた人だけ。外国で働いて3年。電話で、子どもが口をきいてくれない。
- 帰る → 軸2右
- あと少しだけ続ける → 軸2左
- 仕送りを増やす → 軸2左、軸9右
- 子どもを呼び寄せる → 軸5右

（2-6で「行かない」と答えた人には、代わりに次を出す）
収入が足りず、子どもが進学をあきらめると言った。
- 今からでも外国へ働きに出る → 軸2左、軸5右
- 子どもに任せる → 軸7右
- 親戚に頼んで学費を借りる → 軸3右
- 子どもに働きながら学ぶ道を勧める → 軸9右、軸1左

**X-8　順位**　子どもに一つだけ残せるなら、大切な順に並べてください。
お金／学歴／健康な体／信じるもの／帰れる家
- 上位に「お金」→ 軸2左
- 上位に「学歴」→ 軸9右、軸4右
- 上位に「健康な体」→ 軸9左
- 上位に「信じるもの」→ 軸8左
- 上位に「帰れる家」→ 軸2右、軸10左

**X-9　二択**　人生をやり直せるなら、今と同じ道を選ぶ？
- はい → 軸5左
- いいえ → 軸5右

**X-10　選択**　子どもに、いちばん言われたくない言葉は？

## 二重基準の組

「あなたの矛盾」で突きつける組。両方の条件がそろったときに出す。

| 組 | 条件 | 突きつける一言 |
|---|---|---|
| A | 1-2「逃げてもいい」に「そう思う」以上 ＋ 1-9「半年はがんばらせる」 | 他人には逃げ道を、身内には我慢を。 |
| B | 3-1か3-5に「そう思う」以上 ＋ 3-9「頼れる大人に」に「そう思う」以上 | 自分は誰にも頼らないのに、子どもには頼れと言う。 |
| C | 5-2「後悔しない生き方」に「そう思う」以上 ＋ 5-6「安定した職に」に「そう思う」以上、または5-9「止める」 | 自分には夢を、子どもには安定を。 |
| D | 6-1「弱さを見せない」に「そう思う」以上 ＋ 6-9「つらいと言える人に」に「そう思う」以上 | 泣き方を見せないまま、泣いていいと教える。 |
| E | 4-1「平等であるべき」に「そう思う」以上 ＋ 4-7「上の子に出す」 | 世界には平等を、家の中では選別を。 |
| F | 2-2「家族を何よりも優先」に「そう思う」以上 ＋ 2-5「取引先」か2-9「残る」 | 家族がいちばんだと言いながら、家族はいつも後回し。 |
| G | 10-2「見ず知らずでも助ける」に「そう思う」以上 ＋ 10-3「断る」 | 遠くの誰かには優しく、目の前の親戚には冷たい。 |
| H | 8-2「人と違っていい」に「そう思う」以上 ＋ 8-7「周りに合わせるよう言う」 | 自分は人と違っていいのに、子どもには周りに合わせろと言う。 |
| I | 7-2「子どもが決める」に「そう思う」以上 ＋ 7-7「反対し続ける」 | 任せると言いながら、最後は自分が決める。 |
| J | 9-1「今日を楽しく」に「そう思う」以上 ＋ 9-9「遊ぶより勉強」に「そう思う」以上 | 自分は今を生き、子どもには将来を背負わせる。 |

二重基準が一つもそろわなかった人には、揺らぎが最も大きい軸を使う。
例：「あなたは『苦しいことには立ち向かうべき』と『逃げ出してもいい』の両方に、とてもそう思うと答えました。追い詰められたとき、どちらのあなたが出てくるのかは、まだ誰も知りません。」

## 出し方

- 軸ごとにまとめず、混ぜて出す。
